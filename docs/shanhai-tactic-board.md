# 策略道具：棋盘选取、作用预览与结果反馈

2026-11-05，基于 `aca13ed9` 的同一独立分支。

## 本轮交互

在策略背包选择道具后，可继续用原列表确认，也可进入「在棋盘上选取」。棋盘显示当前规则返回的全部合法目标，绿色为可选、金色为已选；围栏和清路标出地块编号，转向标出人物。两位人物同站时使用分开的选取标记，不必点中叠在一起的角色模型。

点选只更新预览，不扣卡。面板显示完整地名、产权、参考租金或转向说明；转向另画出前三站连线和顺序，明确不会立即移动。地图模式也提供原生下拉列表，支持手机和键盘选择，最后必须点击或键盘确认「使用1张」。

进入模式时侧栏设为不可操作，防止背后的掷骰按钮与用牌同时触发；空格不会触发掷骰。未选目标时确认禁用，点到非法位置会清空选择并再次禁用。Esc或取消退出，清理目标标记、恢复镜头和侧栏，退回背包按钮焦点；不修改现金、库存、方向或回合。打开其他弹窗会退出棋盘模式。确认时仍调用原会话规则校验，不信任预览缓存。

使用后在行动区留下「轮次、AI/玩家、姓名、道具、目标、结果」提示，地图突出实际目标。AI也走同一反馈入口，围栏设置/清除仍由已有场景同步显示。提示只用于当前页面，刷新不保留旧提示；游戏效果仍从原存档恢复。

手机隐藏选取期间的普通场景标牌，保留编号目标；桌面和手机均有底部操作面板。转向模式的少量人名与路径标记自动避让，防止同站姓名挤在一起。没有增加动画系统、拖拽框架或新素材依赖。

## 范围与局限

本轮未修改规则、成本、AI策略或存档字段。仍只开放原三种策略道具与遥控骰子。地图标记在手机上较小，保留列表作为等价操作方式；没有拖卡、施法动画或目标模型特效。方向连线只预览前三站，不预测随机事件或保证实际走到哪里。结果提示只保存当前页面最近一次用牌，完整历史仍可看事件日志。实体手机帧率、触屏手感及长期对抗平衡仍未验收。
