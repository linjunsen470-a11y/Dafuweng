# 主游戏峰岳材料：董事会实测与材料展厅

本轮仍在主游戏 `/` 山海都市岛，保留120格、123连接、经济规则、四级升级上限和旧存档，不涉及独立章节的新功能。

## 实际规则和界面流程

99号峰岳材料与股票「远山材料 / 600005 / MINING」关联。到访本身收服务费计入公司金库及周期营收，董事长免付，不自动开放一次额外的政策机会。政策入口是自己的掷骰前「股市大盘 → 公司经营」；最大股东自动成为董事长，每公司每周期只能选一次，费用从公司金库扣除。

明确准备局面：此前真实开局存档只将人类位置改到36号岔路，其余资金、卡片、物品、随机状态不动。通过原有遥控卡选4步，页面选96支路，实际走 **36→96→97→98→99**，扣服务费410，个人现金20,000→19,590，公司金库1,200→1,610、营收0→410。

等到下一次人类掷骰前，实际打开董事会，核实没有持股时政策按钮禁用；切到股票页买入10股远山材料，支付现金3,530、成为本局该公司最大股东与董事长。再切回公司经营，选择「稳健储备」：公司金库1,610→1,260，个人现金16,060不变，不能再选第二项政策。

退出董事会，通过原有遥控道具6步到105号，后续普通掷骰经 **99→100→101→102→103→104→105→106→107→48→49** 返回主路。到第5轮已发生原有周期结算：本次经营亏损限制为50、分红180、政策进入历史并清空当前选择。不是凭代码存在称验收，也没有把准备起点称为从零自然完整对局。102卡片屋只是经过，没有停靠购物。

## 按实测修复决策信息

原董事会政策只显示名称与价格，效果仅在鼠标title提示内；手机不能方便悬停，禁用按钮也不说明缺少董事长资格还是行动时机不符。现在选项直接显示已有规则说明、公司金库扣费后的余额或缺口；明确关联股票名称、最大股东条件、掷骰前时机和每周期一次限制。成功决策展示真实引擎返回的公司支出及余额、个人现金不变，并将键盘焦点移到结果；存档恢复后继续显示已选政策，不允许再次扣费。

只改展示与焦点，不改计费、分红、董事长选举、AI决策或存档格式。没有新增确认弹窗或平行经营系统。

## 原创设施和街道

99号通用设施替换为原创材料展厅：双斜屋顶、采光窗、木色立柱、回收石材样品架和屋顶石块标识。276三角形，沿用项目色板，纯代码建模，无外部图片、字体或模型。Blender源文件、生成脚本、GLB和许可/尺寸清单均保留。

初始截图发现标牌遮住角色一部分，已将展厅与标牌向侧面移动1.5单位，并缩短标牌文字避免裁切。展厅在原公司格旁，窄步道从原36号老街入口沿96—99一侧延伸，低花槽与座椅围绕展厅布置，不新增可走格或路网。设施标识明确到访服务费和股市董事会入口。相邻原有住宅不改经济或等级，后半段山路及卡片屋外观仍未统一。
