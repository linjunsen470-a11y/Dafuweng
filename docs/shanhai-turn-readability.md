# 四人回合信息与竞拍可读性（2026-11-06）

## 实际短局观察

从合法初始存档开始，在真实浏览器逐次操作完整三轮四人短局（海岸、种子314、1倍普通动画、已有AI速览开启），包括掷骰、购地/事件选择、三位AI行动和最终排名。原界面三位AI完整回顾在桌面占约591px、390px手机视窗占约620px；资产区距离行动卡底部约1045/1057px。查看资产需要跨过策略工具、三段回顾和角色反馈，竞拍时原回合提示还会隐藏。选择解决信息拥挤，不新增AI决策或等待机制。

## 改动

- 资产卡直接跟随行动区，四人卡保留姓名、身份、现金、地产数量和净值；职业名称不再每卡重复，能力仍可在选角比较和原能力面板查看。
- 同行回顾默认显示每人的轮次、现金净变动和停点；原产权变化、点券、委托和完整行动日志可展开。原生details支持鼠标、触屏、键盘，后续AI回顾加入时保留已展开条目及条目上的键盘焦点。修正空格展开明细与全局掷骰快捷键冲突；滚动定位给常驻提示留白，避免遮住首张卡。
- 回合提示滚动时保持可见，涵盖人类行动、AI席次/速览、实际竞拍报价者、已结算等待确认和本季结束。资产卡的当前标记在竞拍中跟随报价者，而非已经破产的原行动者；竞拍完成后清除当前标记。
- 竞拍回执仍完整展示获胜者、成交价与款项去向，继续前需要确认，刷新仍读取既有回执。

没有改变骰子、AI费用或选择、清算规则、动画速度设置和存档字段。两图以及双人、三人沿用同一展示。
