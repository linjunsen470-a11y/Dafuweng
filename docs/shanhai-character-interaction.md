# 角色与海岛互动：登船、靠岸和事件反馈

基于 `e6d6dda`，继续 `cloud/dafuweng-playability`。本轮仅改变呈现，不修改经济、AI选择、随机数、移动规则或存档结构。

## 可见变化

- 乘船拆成登船、航行、下船、抵达四个明确阶段。角色沿临时舷梯走到船上，航行时与船同步移动，再走回目标道路格；脚底产权色圈在船上隐藏，上岸恢复。
- 原来的单块船底增加甲板与首尾围板；两个舷梯按阶段出现和隐藏。航行有很轻的船体摆动和角色平衡动作，结束后归零。
- 阿屿登离船较利落、摆幅稍大，青禾更从容。复用现有 walk/idle 等原创动作，不引入新的骨骼系统或外部美术素材。
- 乘船时切回全岛视角；地图提示与侧栏反馈同步显示阶段和实际目的地。潮汐改靠明确标出改靠地点，随后照常显示该地点的来信或经营操作。
- 新角色反馈卡带头像、姓名、事件标题和简短原创短句。侧栏滚动时置顶，避免购买船票后看不到角色反馈；手机采用同一可读布局。
- 两位角色各有 13 类原创反馈，覆盖登船、航行、改靠、下船、抵达、来信、成功、失利、购地、升级、付租、委托与主动能力。失利对应失落动作，其余使用已有通知/庆祝动作；费用与结果仍由原规则界面明确显示。

## 兼容与性能边界

船费和落点仍在动画开始前原子结算并存档；途中刷新直接恢复已结算的落点，不再扣费、不再抽签。人类和 AI 共同调用同一段交通呈现。台词是确定性展示，不调用游戏 RNG、不进入存档。

减少动态时压缩各段时长并关闭船体摆动；1×/2×节奏继续控制航行时长。角色动作继续使用原 GLB，无新增纹理下载。每趟仅 4 个船体网格与 2 个临时舷梯网格；同时只显示正在使用的舷梯，结束或异常后释放几何与材质。单次测试不代表实机性能结论。

## 尚存不足

临时舷梯是风格化呈现，尚未为每个到站点制作独立码头或物理碰撞避让。没有手扶栏杆的 IK、坐姿、口型或配音；角色仍用现有分部动作。手机只验证响应布局和软件 WebGL，未测真实手机帧率与耗电。生产 JS 大包警告仍在。
下一步可围绕各区码头补场景接点和候船岛民，让交通入口与区域生活更自然；仍需长期打磨到完整商业游戏的体验体量。
