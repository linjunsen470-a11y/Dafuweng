# 原创短任务链：海风花灯

基于 `e42dfbf`，继续 `cloud/dafuweng-playability`。仅增加一条可选短故事，复用既有委托、交通、岛民和动画；没有新任务系统依赖或外部素材。

## 四步可完成流程

1. 实际在0号蓝湾出发站，接下阿澜的花灯便笺。
2. 接信后完成任意一单现有海湾委托：速递或焕新均可，已接受但尚未完成的委托也有效。接单本身、过期和过去已完成的委托都不推进故事；阿屿主动接力完成速递仍算一次正常结单。
3. 实际停靠8号海风补给，与小栀交互领取纸灯罩。
4. 实际停靠16号远方来信，先处理原海岛来信，再与木木选择把灯照向归船，或留在花棚。

两种结局为纪念称号「归航之光」「花棚夜话」，各有原创结局短文，并可重读、在季末结果中查看。故事不额外发钱、点券或卡片；普通委托仍只发原有一次奖励，选路、卡片和船票沿用原费用。故事动作本身免费，在本季16轮结束前完成即可，未完成不扣款。

## 玩家反馈与路线取舍

侧栏显示0–4步进度、下一目标和故事入口；岛民窗口显示对应故事行动和不能操作的原因。完整故事页显示四步清单、任务条件与结局。地图目标标记复用现有标记（进行中的速递优先），遥控骰子落点预览也标出故事目标。

经过8号/16号不能代替停靠；买船票仍按原航线到达9号/17号等地点，不会偷偷改到任务目标。这让玩家需要在快速跨区和精确停靠间作取舍。到16号时，故事按钮会先要求处理原来信，避免绕过事件成本或重复领奖。

## AI与存档

每位玩家有独立的 `slice.stories` 小记录，存储阶段、结局、接信轮次与完成的委托类型；原存档键和版本不变。旧存档缺字段时为未接信，不回溯历史结单、不发奖励、不移动玩家。新开局清空故事进度。

AI在实际停靠相应地点时调用同一故事行动入口。现有速递目标优先；故事目标在六步内时，可按正常点券费用购买并使用遥控骰子到站。不能买卡时照常掷骰，没有免费位移、不读取未来随机数。AI处理完16号事件后才能完成故事；阿屿偏向归港灯，青禾偏向花棚灯，两个结局不影响经济胜负。
