# 四人中后期：破产后按轮旁观

2026-11-06，基于 `f8d0f5c5f1c1182f38d3a3622372995e60b1e109`。本轮只改观看与提示流程，不改AI决策、价格、骰子、竞拍或胜负规则。

## 观察与选择

此前的三轮短局记录已解决回顾拥挤和资产区过远，仍有AI速览与常驻行动者提示，因此不重复建设。此次在两图的四人第13轮准备破产场景中，实际执行租金清算、AI地产竞拍及结果确认，发现玩家确认后必须旁观到第16轮终局；中间点击「回到启程页」仍提示“等这一小段行程结束”。`runAI`会在没有人类回合可返回时一直循环，`busy`始终为真，现有菜单无法使用。

开启AI速览、减少动画后的这两个准备场景，确认竞拍到结算约24.6秒（海岸）和3.5秒（山城）。差异受航行动画与落点影响，不用于推断普遍耗时，也不是随机自然局的统计结论。问题是缺少可停下阅读、保存离开的时点，而不是简单提高AI速度。

## 实际改动

人类已经破产时，剩余AI完成当前轮后，在下一名存续AI掷骰前自动暂停。行动卡和常驻提示明确写出「旁观已暂停」及待继续轮次；保留刚完成的同行回顾、资产、关键道具反馈，允许展开阅读和查看棋盘。

提供「继续旁观这一轮」和「保存并回到启程页」两个按钮，键盘可操作。保存失败仍留在当前对局，不强行退出。继续后按原规则完整执行当前轮；终局仍直接展示四人排名。存续人类的双人、三人、四人流程不新增停顿。

停点只允许在PRE_ROLL_ACTION、没有待走步数/债务/竞拍/待确认竞拍回执、AI内部执行已结束时出现。未完成的移动和竞拍不会被切断。恢复到该安全停点的旧存档也先等待玩家继续；恢复中的AI移动仍先执行完。没有增加存档字段、持久开关、调度框架或自动跳过经济结算。

回顾沿用当前会话内的记录，刷新前的回顾不会被重建；界面明确说明，已结算资产和最近动态仍可查看。未伪造缺失历史。
