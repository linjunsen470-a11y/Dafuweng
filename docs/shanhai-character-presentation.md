# 四位角色近看与动作衔接（2026-11-06）

基于 `bd13ac7`，在现有独立分支继续开发。此次选择两处实际可见的问题：选角时完整人物只有棋盘上的小尺寸显示；走多格时每格均切回待机并重新开始步行，动作相位反复归零。四人的原有帽子、背包和工具已有差异，先让这些原创造型更容易看清，再修正动画衔接。

## 实际改动

- 选角区增加「近看所选角色的 3D 造型」。用现有角色、灯光和同一个渲染器显示完整人物；隐藏棋盘与标签，支持拖动、旋转按钮与缩放，附上角色职业及造型特征。返回按钮或 Escape 回到棋盘与选角；直接开始/继续游戏也会恢复正常棋盘视角。默认启程页仍显示整张地图。手机进入近看会滚到画面，关闭后焦点回到入口。
- 中途走格保持同一段步行相位，只在最终停点切回待机。玩家与 AI 使用相同路径；引擎已停止的移动（例如围栏截停）不继续步行。重复同种事件重新播放完整反应；快速换角色后，旧反应的定时回调不能打断同座位的新角色。
- 近看时停止背景环境绘制，退出后恢复；反复换角色释放旧座位圆环及脚底影子的几何体/材质，保留共享人物模型。没有新增画布、灯光、依赖或模型面数。

未修改角色 GLB、原创头像、经济规则、AI 决策、存档结构或版本；这是现有原创模型的展示与动作改进，不是重新建模。两图及四人模式沿用原有数据。
