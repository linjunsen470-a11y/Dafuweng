# 东段海港船修院落与滨水联系（2026-11-06）

基于c10036f，主游戏/山海都市岛，cloud/dafuweng-playability本地独立分支。开始工作区干净。沿用已搜集的原版说明书界面参照：道路、可购买地产与背景街区应共同形成有用途的城市空间，而非逐格更换孤立模型。

## 实际观察与改动

13—24号海港街段已拥有住宅地块、栈桥和船只，但内侧大块空地与海岸没有区域联系。查看13/18/23正常街景及全图后，本轮重点处理其中部船修院地和滨水联系，以海港作业场景区别于北侧市场街屋与银行庭院。

原创建模包括低矮船修棚、支座上的船体、开敞作业棚，共用一块院地和沿街步道；6/26/38三处地块间空隙接入既有滨水步道。船修院落作为景观地标，沿用原地产、事件和交通规则；所有可购买地块仍保留原产权色、标记和进出路径。保留内侧84—95支路及93号地产净空。

新增几何按五种材质合并为5个静态网格、361个三角面，最高2.8；不新增动画、外部素材或框架。船体、屋顶、立面、支座均为原创程序几何。使用暖石/木色与海绿屋顶，与已有海港风格衔接。

## 验证范围

准备原四人存档，仅把玩家位置设为17；读取后players、properties、companies、round、rngState与准备存档一致。实际在界面使用原遥控卡走17→18，点击购地，原费用1479。13/18/23及全图截图是镜头检查，不是额外自然行走。360×640做街景与操作区可见性检查，不等于实体手机或手机完整购地验收。

7项相关检查通过（harbor-yard.test.js与harbor-streets.test.js）：新增实体与全部原道路/地产净空、确定性几何、规模、其他地图隔离及已有海港住宅适配。GrandMapData、GameEngine、GameState、PropertyManager、AIPlayer、main.js与基线逐字节相同，保留120格路线、经济、AI和旧存档结构。修改前后购地结果与完整快照除时间戳外一致，实际页面结果见qa/harbor-yard-*。最终构建通过，保留现有大包体警告。
