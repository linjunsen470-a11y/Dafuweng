# 主游戏山海都市岛：道路、棋子与海岸步道统一

交付入口仍为主游戏 `/` → 山海都市岛，基于 `7a6893b` 公共服务街继续开发，未转到 `/shanhai.html` 独立章节。

## 截图中复现的问题与改动

1. **功能格混用深底小字、食物图案和复杂银行纹理。** 山海都市岛120格改用原创 Canvas 格面：青灰通行格、浅色地产格、暖色设施格，统一中文功能、格号与分岔文字。道路与格座配色同步收敛，所有格面文字方向一致；旧图片不再用于这张地图的格面。岔路方向箭头按真实 `next` 连接生成，包括12→13和12→84，不增加路网。
2. **角色变成矩形立绘，同格姓名条拥挤。** 主游戏此前已有的原创程序化角色一直被立绘加载回调隐藏。本轮只在山海都市岛直接使用这些三维造型，略放大轮廓，恢复跳跃与呼吸动作，取消棋盘立绘卡片；头顶用颜色和编号，完整姓名仍在资产栏。脚底与光圈抬到路面之上，缩小同格光圈；保留原X/Z站位与移动逻辑。
3. **手机视口的四级住宅挡住同格角色。** 仅对样板街区的原创住宅，以相机到角色上身的视线与住宅包围盒判断遮挡，挡人时淡化至22%，产权底座保持实色；移开后恢复材质。每180ms检查一次，不逐三角形扫描，不新增动画。此项不声称覆盖全地图所有旧式高楼、树木或任意镜头。
4. **公共设施、住宅与海岸像孤立物件。** 增加低矮连续服务街铺面、住宅背后的滨水步道和三条窄步行连接，仍是场景铺装，不是新的可行走棋盘路线。四座巨大宽码头收窄为短木栈桥，并用原创程序化木板纹理代替整块棕色面；不添加无功能的大量装饰。

新增格面、箭头、铺装和木板纹理均为程序化原创；角色复用项目已有几何代码，无新外部模型、图片或依赖。历史HUD头像及地图其他旧素材未在本轮统一，不能视为完成全部素材授权审计。

## 保持兼容

- 120格、123条连接与原分岔、经济、AI、角色ID、技能、存档字段不变。
- 四级经济上限不变，第五级继续未开放。
- 手机HUD、暂停/存档菜单与购地弹窗修复保留。
- 新格面和立体棋子仅作用于主游戏山海都市岛；其他地图保留原有显示。

## 实际边界与下一步

本轮是正常主游戏显示的统一，不是完整地图或人物美术成品。现有几何角色仍很简化，缺少精细表情与分段行走；同格时仍可能互相遮挡。遮挡淡化只覆盖原创海港住宅，旧城市高楼、树木和特殊地标仍需逐区检查。外围景观与其他街区的密度、风格还有差距。

页面验证使用准备的相邻落点，未做完整自然对局或全地图镜头扫描；手机为浏览器视口模拟，不是实体手机、稳定帧率或iOS Safari验收；未进行主观音频验收。下一步仍宜沿公共服务街继续统一相邻街区与角色质量，不增加外围玩法系统。不推送、不发布、不绕过Space认证。
