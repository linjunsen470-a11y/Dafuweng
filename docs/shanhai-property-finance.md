# 地产现金与租金比较（2026-11-06）

检查现有买地、升级、竞拍与商业账本后，发现章节界面只有升级报价，没有主动抵押/赎回入口；核心引擎已有这些规则，自动偿债也在使用。本轮把原“异地施工”入口扩展成“地产管理·周转/升级”，不另建交易系统或重复资产面板。

## 实际功能

选一处自有地产，在同一张表比较保持现状、抵押或赎回、异地升级的操作后现金和本站单次参考租金。按当前位置、方向与围栏，显示前方1–6步最高参考租金，以及支付该笔租金后各方案的现金余量；注明不是必然停靠、每轮收入或全局支出预测。

抵押与赎回调用原引擎命令：只有无建筑的自有地可直接抵押，得到土地原价50%，保留产权并停止本站租金；赎回支付原抵押款加10%手续费。报价展示即刻净值变化，抵押款不是收入。花园抵押还会暂停访客回馈与邻地加成，详情列出每处受影响自有地的实际租金前后变化。

有建筑、挂牌、研发占用、错误阶段、现金不足等情况显示原因并拒绝执行。本轮不提供自动拆楼。抵押/赎回不占原策略机会，异地升级仍在第8轮开放、收上门费并占策略机会；普通落地升级与竞拍规则不变。抵押/赎回后先显示回执，再由玩家返回比较页，避免连续点击意外立即执行相反操作。

## 规则与兼容

新 `SlicePropertyFinance.js` 只生成预览，租金使用独立的产权副本和原租金计算器，不修改现金、产权或随机状态。真实操作经过原命令校验、产权检查和费用计算，继续更新原资产、统计与日志。核心存档格式、地图存档键与已有字段不变，没有新增债务系统。

人类和AI席位遵守相同价格与操作限制；相关测试在第1、4席验证相同命令与费用。**AI决策与自动偿债策略沿用原实现，本轮没有加入AI主动抵押/赎回的新偏好**，不声称优化了AI投资水平。完整引擎已有的产权管理和清算逻辑没有修改。

## 限制与后续

只接入无建筑地产的主动抵押及已有抵押的赎回，未增加主动拆楼、玩家间议价交易或新的AI财务策略。风险比较仅为前方六步当前产权的单笔参考租金，不涵盖随机事件、竞拍、个人免租或所有未来回合；没有进行长局经济平衡和实体手机性能测试。
