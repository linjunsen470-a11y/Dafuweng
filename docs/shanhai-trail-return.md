# 茶坡返程：地图路线选择

## 依据与范围

两张地图均有24站，来信位于4、10、16、22号，点券补给位于8、20号，宝箱位于18号。山城4、10、16号原来都主要在稳妥资源收入与概率现金投资之间选择，16号又与海岸16号共享委托延期思路。相比继续叠加新的赌博奖励，本轮选择让山城16号影响真实后续路线。

新增原创「请茶农带路返程」，嵌入已有茶坡互助日，复用方向与移动规则，没有新增地图节点、任务链、卡片或存档系统。原采茶、茶摊、延期及山城故事继续保留。阿棠的向导文案原创，使用现有原创人物与场景。

## 玩家选择

- 保持方向采茶：稳妥获得¥220。
- 请向导返程：支付¥250，只反转自己的方向，持续到再次转向。这次不领取采茶收入，相对采茶少¥470现金，换取另一侧路线。仍停在16号，下回合再走，不加掷骰、不免租、不消耗卡片。
- 原有试饮茶摊和委托延期仍可选择；一次来信只能选择一个方案。

返程选项内显示两方向1–3步停点、六种普通骰子点数的参考平均租金及付款后现金。使用现有可见产权、物价、新闻与第一处围栏；不预测个人状态和随机事件，也不把较低租金称为必然更优。反向行走者也可使用，实时站点预览会相应交换。区域介绍及棋盘事件预览可在到达前了解此机会。

不足¥250时禁用且不扣费。落地事件结算后不能重复付款；刷新保留方向和结算结果。返程不改变原策略机会，不处理已有围栏，下一回合仍按正常规则用卡与移动。

## AI与兼容

AI使用同一选项、价格和结算函数。仍优先处理临期委托；在没有现成回程路签时，将两方向的可见参考平均租金差计入方案比较，只有足以抵付费用及放弃其他收入时才选择返程。它不读取未来骰子或事件，也不是完整路线优化器。

使用原player.direction与事件结算账本，不增加保存字段。旧的待选茶坡事件恢复时会加载新选项；已结算事件不重播。两图存档键不变，海岸没有此选项。
