# 可选局长：12轮短局与16轮标准局

2026-11-06；基于 `84d2dada47e6c2cac58cc9e625a21ff9d397d0e1` 继续现有独立分支。

## 选择与实际改动

现有 `SliceSession.start({maxRounds})`、引擎末轮判定、存档和结算已经支持指定局长；之前界面固定开16轮，还把轮数栏与部分帮助写死为16。因此本轮只接通已有能力，没有新增胜利算法、存档字段或模式框架。

启程页提供「标准局 · 16轮（默认）」和「短局 · 12轮」。选择12轮是为了提前4轮结算，同时保留第8轮开放后的经营空间。说明明确提示：短局用于后期建设、探索故事的机会更少；初始现金、价格、能力冷却和异地施工开放轮次相同。每轮存续角色各轮到一次，停留等状态照常跳过。达到轮数后按原净值规则决胜，单一存续玩家仍可提前获胜。

轮数栏、启程页轮数标示、两图帮助、海湾故事期限说明均读取所选或当前存档的局长。结算沿用真实上限；「同阵容 · N轮再玩」保留人数、角色和局长。返回启程页时可改选另一局长；新打开页面仍默认16轮，没有跨地图全局偏好。

继续存档只按存档的 `maxRounds`，不会被启程页下拉框覆盖。原16轮存档照常恢复；既有自定义轮数存档（验证用3轮）也能继续与同长度重玩，新开局界面仅提供12/16。两图保存键不变。

## 局限与下一步

短局只减少轮数，不保证固定分钟时长；动画设置、路线、事件与竞拍都会影响耗时。故事可能来不及完成，晚期投资回收期更短，能力使用次数也自然减少；没有为12轮另调价格或奖励。只做两张图的小范围验证，没有广泛平衡统计、完整12轮GUI长局或真机性能测试。

下一步可观察自然短局中的投资和任务取舍，确认玩家是否理解剩余轮数，再决定是否需要更具体的末期提示。此前提交和恢复包保留；本轮未推送、未发布，也未重试或绕过Space认证，仅保存云环境本地检查点。游戏仍为开发版。
