# 主游戏卡片目标与结果反馈

2026-11-06；基线2030cb3；独立分支cloud/dafuweng-playability。

## 实际流程与缺口

沿用已完成的原版研究（richman4-map-integration.md）：卡片策略应能让玩家理解目标与实际影响，而不是只堆发动效果。本轮主游戏山海都市岛准备局面：顾田野拥有1号地LV2，林小满持拆房卡和乌龟卡；通过真实背包按钮先取消一次拆房，再选择该地产拆房，随后选择顾田野施加乌龟。没有直接调用引擎来伪装页面操作。

取消后卡片及地产等级不变；实际拆房后LV2→LV1；乌龟持续3回合；现金不变，卡片各消耗一次，仍在可掷骰阶段。基线提示数据却只有DEMOLISH/TURTLE，无目标和结果。主游戏state没有卡片目录方法，而提示未使用已有目录回退；发动大动画虽然能显示中文卡名，但仍不说明具体影响。

首次脚本末尾误写掷骰按钮选择器而失败，保留card-result-initial-harness-*；修正选择器后基线完整通过。基线截图有部分错过短暂提示，不把日志数据当作截图中可见文字。

## 修复

只修改PresentationUI的CARD_USED描述。沿用现有卡片目录显示名称，拆房卡显示地名和结算后的等级；乌龟卡显示目标名字和结算后的实际持续时间，不写死3回合。目标缺失时不编造结果。用现有完整详情提示显示在棋盘上，不新增模态、不拦截点击、不增加回合等待；窄屏沿用既有完整详情优先于装饰台词的处理。未添加素材、改变经济/卡片规则/AI/地图/存档。

## 限制

明确为准备局面，不是自然整局；本轮只验收拆房和乌龟两张卡，不代表其他卡片或科技道具全部验证。没有验证对手之后的完整三回合行动或全部反制组合；其他卡片仍可能缺少具体结果说明。软件WebGL/手机视口不能替代实体手机与长期性能验收；未试听音效，不跑全量测试，不声称解决旧CI全部问题。
