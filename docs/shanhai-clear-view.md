# 清晰俯视与可见操作位置（2026-11-06）

基于 `32dee02`，继续处理四人棋盘中的建筑和植物遮挡。两图准备存档均有四名角色停在9号地产，四处地产升到L4，用于直接观察远景、近看和手机点击；不将准备存档当作自然对局的平衡数据。

## 本轮交付

- 新增「清晰俯视 / 返回立体」切换。清晰视角提高摄像机，并限制拖动时的俯仰范围；原立体视角仍可随时使用。全景、旋转、同格近看和花园视图沿用当前模式。
- 清晰视角中，同格人物沿道路切线排列，减少伸入外侧建筑的情况；原有身份色环保持可见，即使部分身体仍被树冠挡住，也能定位棋子。人物模型与场景材质不变，没有逐帧射线检测或场景透明系统。
- 选中地产显示一个可复用的虚线边框及与道路站点的连接线，选中圆环不会被场景遮住；转到事件站或策略选目标时隐藏地产边框。关闭清晰视角恢复原有显示。
- 实际手机点击发现右侧工具列截获地产位置，已将视角工具移到棋盘下方的独立工具栏。画布为工具栏留出空间；同格入口、地产点选与视角工具各有可点击的位置，骰子反馈移到工具栏上方。选角人物近看仍使用原工具布局。
- 系统要求减少动画时，站位调整直接就位，选中圆环不再闪动；模式切换没有新增盘旋镜头。模式只在当前页面保留，刷新后恢复立体视角，不改变游戏存档。

增加一个简单线框对象，位置与虚线距离缓冲区反复更新复用；身份色环复用原网格。没有新增框架、依赖、人物资源或额外渲染画布。规则、经济、AI及存档结构不变。

## 限制

清晰俯视降低了部分场景立体感，因此保留为可选模式。它优先保证棋子位置、地产范围与操作入口可辨识，并不保证所有角度下每个人物身体都完全无遮挡；仍可使用同格详情和近看。未实现遮挡建筑自动淡出、全地图标签避让或实机低端手机性能测试。未覆盖全部旧存档组合或长期完整对局。
