# 竞拍后的租金与产权联动预览（2026-11-06）

## 试玩发现与改动

在四人局首位破产后的真实竞拍页面，旧界面仅显示原地价、等级、出价规则和余额；无法在出价处判断地块的收租能力，以及补齐街区或买入花园对已有地产的影响。基线页面文字保留在`qa/auction-preview-baseline-report.json`。

本轮在报价前加入简洁的「竞得后参考租金」：以当前报价者拥有该地块为假设，保留地块实际等级与经营类型，显示每次参考租金。已有地产的租金变化默认折叠，可以逐块查看原值与竞得后的值。花园清楚显示自身租金为零及邻地收益，避免将购买花园理解为直接收租。

预览只复制产权数据并调用现有PropertyManager租金计算，包含物价、新闻、完整街区和花园影响。按步行访客计算，不含免租等个人效果；需要对手实际停靠，不是每轮收入或未来收入预测。不会使用随机数、改变产权、余额、AI估值或存档字段。AI轮到报价时也按该AI自己的产权显示预览。旧存档无需迁移。
