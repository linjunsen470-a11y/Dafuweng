# 主游戏榕树老街：从海港到交易所

本轮入口为 `/` → 山海都市岛，沿用原地图的 OLD_1 榕树老街（31、33、36、38号住宅）。独立章节 `/shanhai.html` 未接入这些改动；不新建地图，不改变120格、123连接、四级经济上限或存档结构。

## 实际观察和改动

从准备好的四人23号海港存档开始连续操作，正常随机掷骰6、5、4，走到29号魔法屋、34号道路，再经36→37岔路到38号购地。AI正常行动及住院跳过、轮次新闻和利息照常发生。共4次按钮点击，其中一次过渡期间未形成掷骰，实际只有3次掷骰；不是从标题界面开始的完整自然对局。

离港后的老街以空地、通用设施为主，原镜头沿纵向道路看去，街道两侧不易同时读清。本轮集中深化这一段：

- 31、33、36、38号住宅接入已有原创 `res_market_1…4` 模型，采用克制的灰绿屋顶与暖石墙面，保留各级轮廓、产权底座和朝向道路的入口；克隆材质隔离，不改海港住宅或原模型材质。
- 为原32号股票格新增原创低面数交易所：柱廊、砖墙、绿顶及钟楼，共616三角形。模型和Blender源文件、生成脚本均保留。功能仍是原股票买卖与公司经营，路牌明确“到访看行情 · 掷骰前买卖”，步道连接真实地块。
- OLD_1沿线加入低矮连续石铺面和交易所前场；地块标注“老街”，30号路格标“老城”，36号继续优先显示真实分岔。其他老城住宅群、35号商业地和29号魔法屋没有换模。
- 这一段的读档、跟随和落点镜头改为横看街道，显示两侧地产与交易所。范围外继续原取景，保留自由镜头与已有遮挡淡化。
- 实测发现手机股票窗口固定双栏把买卖按钮裁到屏外，改为窄屏单栏、可滚动股票列表、自适应走势图和44px交易按钮；标题、分页与关闭入口保留。随后实际点击发现落地阶段按原规则不能买卖，原窗口却没有说明且错误日志为undefined；新增时机说明与禁用态、正确显示失败原因，保留掷骰前交易和偿债时可卖出的原规则。

本轮交易所为原创程序建模，无外来贴图；住宅复用项目已有原创资源。主游戏其他历史素材的完整授权审计仍未完成，不作为可发布成品。

## 仍有缺口

老街以外的老城建筑、商业地和魔法屋仍是旧外观，背景街区仍较稀疏，尚未形成完整统一城市。手机小视口只能展示局部街景，需要随走棋观察各地块；角色造型仍简化。没有验证实体手机、Safari、设备帧率、完整自然对局平衡或主观听感。此次视口检查使用Chromium软件WebGL，不能替代真机验收。

本轮只做局部地图整合与实际操作修复，第五级仍关闭。不推送、不发布、不绕过Space认证。保留旧提交及恢复包，在本地完整Git bundle、构建和QA证据打包后校验CRC和逐文件SHA。
