# 主游戏山海都市岛：海港公共服务街

本轮入口为主游戏 `/` → 山海都市岛，范围是7号卡片屋、9号乐透站、12号银行一段街区。不是 `/shanhai.html` 独立章节，也不是仅在检查脚本中加载的美术预览。

## 先核对功能，再改街景

| 原有格子 | 已有真实功能 | 本轮正常游戏中的呈现 |
| --- | --- | --- |
| 7 山海卡片屋 | 停靠取得本轮货架、到店点券/折扣，以点券兑换卡片或道具 | 将原先纯装饰的原创钟楼商廊移到真实卡片屋，保留钟楼、条纹遮棚与柜面轮廓 |
| 9 山海乐透站 | 现金选号购买，按原经济周期开奖 | 新原创小型售票亭，珊瑚色折顶、三枚金色号码盘、票券窗口 |
| 12 山海银行 | 存取款；出发时可走13或84 | 新原创柱廊银行、青绿檐口与金币徽记；招牌同时说明银行与分岔 |

实际发现：旧 `rebuildMapLandmarks` 先判断岔路，再判断设施，因此12号银行只显示岔路标志。本轮在三处明确匹配的海港设施上优先生成对应建筑，并保留原路线选择。规则与AI仍通过原来的 `CARD_SHOP_OFFER`、`LOTTERY_OFFER`、`OPEN_BANK` 和原交易命令执行。

## 布局和可读性

- 公共设施统一放在道路内侧，住宅继续在海岸侧；建筑朝向对应格子。步道指向原格号，止于道路边缘，不增加通行边或可落脚格。
- 三处建筑及全部原道路的间距经过几何检查；银行避让12→84斜向支路。没有占用住宅地块。
- 删除原来的重复装饰钟楼，将可识别的钟楼用于真正的卡片屋；保留旁边咖啡桌椅和船屋，形成公共服务街与住宅两侧层次。
- 设施不再上下漂浮；地面高度与步道对齐。模型异步加载后更新真实地标，同时恢复已有产权外观；删除旧地标时回收几何、材质和自有画布贴图。
- 招牌显示格号、设施名称及简短用途。手机截图复查后加大名称、缩短附文，提高对比度，避免灯光色调映射令文字发灰。
- 加载失败时保留程序化设施兜底。没有修改摄像机、手机HUD、120格路网、四级经济上限或存档字段。**用户已明确第五级暂不开放，本轮未加载第五级模型。**

## 原创资源

新增 `public/shanhai/models/harbor-facilities.glb`，两座建筑合计576个三角面，约47KB。模型使用手写几何和配色，无外部贴图、字体或原作素材。

可编辑源文件 `art-source/shanhai/harbor-facilities.blend`；生成脚本 `scripts/art/create_harbor_facilities.py`；授权与尺寸、面数记录在 `public/shanhai/models/harbor-facilities.manifest.json`。钟楼商廊复用项目此前原创 `neighborhoods.glb`。

- `npx vitest run harbor-facilities.test.js harbor-streets.test.js`：8项通过。涵盖道路间距、朝向、地图范围、银行与分岔同时存在、120格/分支不变及住宅资源隔离、初始光照。
- `node test-main-harbor-facilities.js`：真实 Chromium/WebGL，从准备好的四人旧格式存档进入正常主游戏，在实际掷骰后兑换卡片、购买3号乐透券、手机银行存入1000；从12号格出发选择84号支路并实际移动。并对照读档前后玩家、产权、轮次与随机状态不变。

## 仍有不足

这是局部可玩街区，不是整张地图美术完成。主游戏人物仍是旧式立绘棋子，路面图案及部分旧设施的风格尚未统一；外围草地、植被和街区衔接仍比较简略。手机上的招牌附文属于辅助信息，详细费用和选择仍需停靠后查看原有界面。地图建筑没有新增点击直达交易功能，交易遵循原停靠规则。

页面检查使用准备好的相邻落点，未进行完整自然对局、长期经济平衡或全地图遮挡统计；手机为浏览器视口模拟，并非实体手机、iOS Safari或帧率验收；本轮未做主观听感检查。新增素材原创，历史主游戏其余素材不能由此视为完成授权审计。没有推送、发布或尝试绕过Space认证。
