## 实现

复用现有原创关节身体和行走姿态：丹尼青色衣服/耳机，莎拉蓝色研究服/浅色外衣/眼镜，宫本凌粉色束发/剑鞘，金宝宝黄色帽子/金币围兜。保留原有姓名、角色ID、配色和技能。八名已支持角色的模型和头像共用轻量支持列表，避免选角头像支持与模型支持脱节。

选角、玩家卡、回合与角色反应使用同一模型渲染的静态PNG；切换其他地图时恢复原图。未更换其他地图的人物、未改存档字段、AI或经济。模型尺寸及几何预算沿用已有局部约束，同格布局不变，不引入新加载框架。生成脚本可复现全部八张原创建模头像。

## 验证范围

- 通过真实选角操作选12—15，四人均设为人类用于依次操作不同角色。改前/后实际遥控骰：丹尼0→6购地1320；莎拉0→1购地1000，完整购买事件比较一致。两次新开局的随机种子不同，不宣称完整对局状态相同。
- 首次基线脚本遗漏多人交接“我准备好了”而超时；页面正常等待交接。修正脚本后再测，保留失败证据，没有改变游戏规则。
- 最终实际页面通过手动槽保存/读取，玩家、地产、公司、轮次和随机状态与保存前一致；角色和地图切换后的选角头像正确。桌面1280×800及390×844手机视口截图已核对。
- 8项局部检查通过，覆盖八名支持角色的模型预算/尺寸、动画、资源释放、角色顺序与头像对应、同格及遮挡。未跑全量测试。
- `npm run build`通过；保留已有的大块体积提示。未做实体设备帧率基准。
- protected-report证明BoardData、120格地图、经济、AI、存档和同格布局源码字节不变；main.js仅改选角头像展示与地图切换刷新。

## 未覆盖

仍有8名旧造型未统一；竞拍和部分特殊事件仍使用旧头像。新人物仍是程序化Q版，共用头身比例，尚不具备精修表情、服装细节及专属事件动作。手机仅浏览器视口，不是真机；仅两位新角色实际走动，另外两位验证选角和棋盘出现，没有覆盖所有技能、AI完整局或旧PR的全部CI。没有推送或发布。
