## 验证与边界

- 真实选角4—7号开局，风间岚遥控骰0→6购地1320，米娅0→1购地1000；前后购买事件比较一致。新开局随机种子不同，不声称全局状态相同。
- 第二组实际选8—11号开局，四名新模型正确出现；第一组手动槽存读后，玩家、地产、公司、轮次和随机状态一致。桌面1280×800与第一组390×844手机视口截图已核对。
- 截图发现黑泽隼姓名深灰色在深底上难读，仅将HUD姓名文字改浅灰，角色配色和保存值保持不变。补查通过真实开局与首次引导关闭核对姓名计算色和保存色；保留引导遮挡时的截图，不将其作为姓名可读性证据。
- 8项局部检查覆盖全部16名的尺寸/几何预算（单模型不足6000三角面）、共享动画、资源释放、头像和席位对应、同格布局及遮挡恢复；未跑全量测试。
- `npm run build`通过，新增头像纳入离线清单；保留已有的大块体积提示，未进行真机帧率基准。
- protected-report核对角色资料、规则、存档、AI、地图、入口及PawnManager与基线字节相同。
- 仍是共享Q版比例与程序化模型，未达到精修服装、丰富表情和角色专属事件动画的完成度。竞拍及部分特殊事件仍用旧头像。其他地图未统一；只有风间岚和米娅本轮实际完成移动/地产操作，其余6名验证到选角和开局；没有对全部角色技能、AI完整局、所有镜头或实体移动设备作验收。旧PR的CI余项未在本轮处理。

本轮仅本地提交、构建和恢复包，不推送、不发布。
