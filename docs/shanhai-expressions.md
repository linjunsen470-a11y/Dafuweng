# 三位原创角色的面部表情（2026-11-06）

## 实际变化

原角色已有庆祝、低头等身体动作，但脸部固定。本轮在原有头部几何上制作happy、concern、surprise三个稀疏位置变形，分别改变眼睛开合、眉形、嘴形与轻微腮部姿态。阿屿喜悦时眼睛更弯窄，青禾保留叶饰与柔和眉形，星罗保留眼镜和宽帽，担忧眉形幅度较克制。没有新骨骼、三角面或角色替换。

游戏中的购地、升级、委托、能力、成功事件触发喜悦；付租、失败与船只改靠触发担忧；收到事件和登船提示触发惊讶。棋盘头部使用实际变形，已有身体动作继续播放，人物标签短暂标注情绪。约2.4秒后脸恢复平静；新反馈会覆盖旧表情，减少动态效果设置下也保留静态面部反馈供阅读。

反馈栏头像由相同运行模型在Blender中直接渲染，三人各三张，256×256透明PNG。反馈栏把原42px头像放大为桌面88px、手机76px，并标注情绪文字，最后一条头像和对话保留直到后续反馈。正常棋盘镜头下脸仍较小，放大反馈头像是主要阅读入口。启程头像与玩家资产卡仍保留原平静头像。

## 原创来源与重建

全部使用项目自建人物、材质与拓扑。面部变形数学和渲染脚本原创，无下载素材、无未授权纹理。原.Blend基础角色、未合并GLB和六组身体动画保留；带表情的运行GLB可导入Blender编辑形态键。

```sh
python3 scripts/art/create_shanhai_expressions.py
blender -b --python scripts/art/render_shanhai_expressions.py
```

修改基础建模并运行原导出流程后，须再运行以上两步，恢复面部形态和匹配头像。优化器默认仍支持原静态合并；专用入口在合并时添加稀疏形态，不对已优化网格反复变形。

## 性能与兼容

三人仍各6个合并网格、每个普通渲染通道28次绘制，三角面分别16,172 / 18,476 / 18,160。运行GLB分别712,848 / 766,304 / 781,600字节，总增量259,352字节；9张PNG合计883,814字节，按实际反馈加载。三角色展开后的形态POSITION数据合计694,080字节，此数字不是整个GPU内存占用。增加了形态着色与图片开销，但没有额外3D绘制批次。

表情只存在于场景对象和DOM，不使用规则随机数、不写进存档、不改变经济/AI规则。角色克隆各自有变形权重，不会让同模型预览或其他人物跟着变脸。读档从平静脸开始，原人物、现金、道具、委托与故事照常恢复。
