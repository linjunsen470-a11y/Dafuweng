# 山海都市岛 · Coastal Architecture Asset Pack

Original Blender-authored geometry, generated by `scripts/art/create_shanhai_buildings.py` with Blender 4.3+. No downloaded models, texture maps, reference-game assets, or external fonts are included. The project owner may use, modify and redistribute all generated artwork.

## Runtime interface

Load `/shanhai/models/buildings.glb` once with Three.js `GLTFLoader`. Prefabs overlap intentionally in the asset scene. Do **not** add the full asset scene to the game. Select and clone a named root:

```js
const pack = await loader.loadAsync('/shanhai/models/buildings.glb');
const house = pack.scene.getObjectByName('property_level2').clone(true);
house.position.set(worldX, groundY, worldZ);
house.traverse(o => { if (o.isMesh) { o.castShadow = true; o.receiveShadow = true; } });
world.add(house);
```

Root names: `property_level0`, `property_level1`, `property_level2`, `property_level3`, `property_level4`, `market`, `lighthouse`, `tree_round`, `palm`, `shrub`, `flower_planter`, `bench`, `streetlight`.

GLB axes: Y up, entrance toward +Z. Origins are ground center. Each prefab has one consolidated mesh child with a small shared material palette. Clone transforms are independent; meshes and materials may stay shared. Do not recolor the entire building for ownership; use a separate ground ring/plinth. The triangle manifest records exact dimensions in Blender coordinates: X width, Y depth, Z height. Three.js dimensions are X width, Y height, Z depth.

## Design

- Level 0: surveyed garden lot with small fence and flower bed.
- Level 1: low cottage, pitched articulated terracotta roof, capped chimney, shutters.
- Level 2: shop-home, striped canopy, framed store glazing, upper residential windows.
- Level 3: asymmetric terraced apartments with projecting balcony and rooftop garden.
- Level 4: stepped boutique midrise with cornices, two rail balconies and roof suite.
- Market: broad hall, three canvas-shaded produce counters, teal cupola.
- Lighthouse: tapered ivory shaft, coral bands, geometric lantern and broad teal cap.
- Environment: rounded broadleaf tree, curved palm fronds, shrub, flower planter, slatted bench and lantern streetlight.

Cream plaster, coral tiles, muted teal shutters and railings, warm wood, jade foliage, pink/yellow flowers. Beveled masonry, full geometric windows and awnings, roof rolls and real silhouettes are visible from the game's oblique camera. No flat sprite billboards.

## Rebuild and QA

Run from repository root:

```sh
blender -b -t 4 --python scripts/art/create_shanhai_buildings.py
```

Outputs:
- `public/shanhai/models/buildings.glb`
- `public/shanhai/models/buildings.manifest.json`
- `art-source/shanhai/buildings.blend` (source scene with all prefab roots at origin)
- `art-source/shanhai/buildings-contact-sheet.png` (inspection render only; presentation offsets are not saved/exported)

The asset uses material colors only and needs no external texture requests. Suggested runtime scale is 1.0. Plants and benches can be scaled to the board composition. Front windows are intentionally detailed more heavily than the back to support the fixed oblique board view.
