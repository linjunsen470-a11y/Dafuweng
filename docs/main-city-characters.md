# 主游戏四位默认人物与行走反馈

2026-11-06；主游戏 `/` 山海都市岛；基线 b571baacf8913ac1385f9ea8cab0e62ef9ef15f8。

## 选择依据与实际改动

对照已收集的原作说明书画面（本地 full-09.jpg；来源见 richman4-map-integration.md）及实际开局截图，原有棋子主要靠颜色和锥体/柱体区分，缺少四肢动作，整个身体每步跳起约1.3单位。人物是玩家跟随路线的主体，比继续增加街边摆件更值得先改善。

为默认四位角色0—3制作同一风格的原创程序化全身模型：双发髻、宽檐帽、眼镜短发、头巾分别保持辨识特征，统一头身比例、眼睛、衣领和鞋。增加髋部、肩部关节，在真实逐格移动时面向路径、交替摆腿摆臂；根节点贴地，停下恢复常用镜头朝向。减少动态模式取消摆臂与身体起伏，移动终点、时长和规则不变。同格布局、产权圈及编号沿用，编号高度适配新模型。销毁人物时释放新增资源。

仅接入山海都市岛默认四人；其他角色和地图维持原模型。未改变角色能力、头像、经济、AI、120格拓扑或存档格式。

## 验证证据

- 使用原有四人开局存档，通过真实页面载入、遥控骰选择6、0→6移动及购地1122；未改玩家位置。为观察动作，使用现有UI的0.5倍速。
- baseline/final报告记录购买事件和完整状态，忽略时间戳后相同。最终四个新模型均存在，采样确有腿/臂动作，根节点保持地面高度0.48。基线根节点最高约1.779。
- 1280×800桌面及360×640手机视口截图核对同格角色、编号和操作按钮；仅浏览器软件WebGL，不是真机验收或完整动画听感验收。
- city-characters.test.js及harbor-pawn-visibility.test.js：7项通过，覆盖四人尺寸/几何预算、摆臂、减少动态、移动终点和时长、资源释放。测试中负零比较及一处拼写错误已修正后重跑通过；不据此宣称运行时代码出错。
- `npm run build`通过；构建文件哈希已保存。
- protected-report逐文件核对规则、地图、入口及角色资料与基线字节一致。
- 减少动态仅局部测试验证，未额外跑实际页面；正常速度/快速模式、其他路径镜头及完整局未覆盖。未跑全量测试，原PR其余CI差异仍未全面验证或解决。

## 仍有差距

远景人物仍小；程序化脸部、衣服和动作不等于精修角色美术。UI头像仍是原有画风，其他八位角色未统一，尚无完整表情/事件动作体系。整体城市色彩、道路与景观层次仍需打磨，本轮没有新增装饰或改变地图。没有推送、部署或发布。
