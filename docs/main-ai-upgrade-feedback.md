## 观察与选择

重新查看既有原作研究与官方说明书本地 full-09.jpg：地图中的资产与角色信息应帮助跟随经营结果。本轮未复制素材或移植原作规则，优先修复连续行动时的归属歧义。

## 修复与验证边界

修改升级结果提示：增加行动者姓名，复用现有完整详情样式与4200ms显示时间，避免窄屏省略身份/地名/费用。提示不阻断操作；回合等待、现金浮字和引擎不变。建筑仍按真实升级结果更新。

第一轮390×844截图发现完整升级提示仍被人物台词遮挡（保留 ai-feedback-mobile-overlap-*，其脚本通过不代表视觉通过）。补充窄屏CSS：完整结算提示可见时，暂时隐藏装饰性人物台词；不隐藏决策或结果，也不累积额外等待。提示结束后台词按原生命周期恢复/结束。桌面行为不变。

测试脚本 test-ai-feedback.js 会记录真实命令、落点、现金和提示；改后逐项对比基线最终玩家及全部产权结果。基线报告中的 upgrade.rect/whiteSpace 误采到了图标而不是文字，保留原记录，不据此宣称文字布局通过；改后修正采样目标。截图本身及提示文本是基线归属缺失的证据。

桌面改后真实截图 ai-feedback-final-upgrade.png 已显示“顾田野 AI · 蓝湾码头 1号 · 投资 $550”，即使顶部进入洛晶晶回合也能识别归属。完整44条命令/结果记录、玩家现金和产权与基线一致。采样点在淡入前，opacity仍可能为0；实际可见性以随后截图为证，不宣称解决了所有提示动画问题。

只运行 upgrade-feedback.test.js 的针对性检查，不跑全量测试。该检查确保在当前回合已切换时仍能按事件playerId给出正确升级者，且不改变现金提示或事件数据。

最终390×844真实截图 ai-feedback-final-mobile-upgrade.png 已显示完整升级者、地名和550费用，人物台词未遮挡。手机同段44条命令/结果与桌面基线一致。桌面1280×800、手机390×844均为 Chromium 软件 WebGL。

npm run build 通过，仍有既有大分包警告。源码比对确认仅 PresentationUI.js 和 style.css 改动。

## 未覆盖

本轮为准备局面的短回合，不是自然完整对局；手机视口不是实体手机。未验收所有地图、全部角色升级、长期经济平衡、完整旧存档矩阵、声音或此前其余CI失败。原有较大的回合/人物反应仍会短暂覆盖地图，本轮未扩展改造整套HUD。
