## 实现

新增`CityGround.js`，只为`grand-bay`生成一次1024×664原创Canvas地面纹理：沿真实已有道路形成连续港口暖砂铺面、老城灰褐铺面、商务灰绿铺面与山路过渡，颜色在相邻路段间渐变。没有新增道路、格子、路径编号或可交互目标。

中央旧楼群有共同的低对比广场地面，西侧原山体通过层叠绿带连成一片，99号后方空地形成低矮田园底纹。四个原有突兀亮色田块改为融入地面的细行纹理，位置及功能不变（原本就是场景装饰）。保留建筑、树木、产权和功能设施，不增加高大遮挡物。

地面平面位于y=−0.095，低于道路与地块，上下范围与原岛屿一致；只新增2个三角形、1张纹理，删除4个旧田块网格，净减少3个网格。纹理RGBA基底约2.59MiB，不含mipmap；统一限制为1024宽，没有每帧重绘或新增依赖。纹理细纹使用独立固定种子，不消耗对局RNG。离开地图时沿现有资源释放流程销毁纹理。

## 实测与验证

- `test-city-ground.js`改前、改后都真实加载同一原有开局存档，玩家、产权、公司、轮次及随机状态与输入相同。
- 页面“全图总览”按钮及海港跟随视角；99/72使用明确标注的镜头检查，玩家未走到那里。桌面1440×900和360×640窄视口截图均保留。
- 实际通过原遥控卡从0走到6，在购地窗口点击购买，现金20,000→18,878、产权归玩家0。两次购地完整结果及存档仅排除`savedAt`和日志墙钟`time`后完全相同，包括经济、AI相关状态及RNG。没有为截图改变经济或造假骰子。
- 7项现有相关检查通过，覆盖所有编号格/岔路方向、人物与产权遮挡保护、上轮院落净空及镜头；没有跑全量测试。
- 浏览器独立检查确认：地面生成不改地图，重复生成纹理SHA相同，范围x±71/z−49至43、最大高度低于0；其他地图不接入；纹理销毁事件正常。见`qa/city-ground-surface-report.json`。
- `npm run build`通过，保留既有大于550kB分包提示。构建文件哈希另存。

`qa/city-ground-{baseline,final}-overview.png`是相同全图取景；同前缀`street-0/99/72`及`mobile`用于局部比较。云朵与环境动画按墙钟运动，两次截图云位置不同，不能把这种差异归因于地面修改。

## 尚未完成

这是一轮地面与街区衔接，不是新增建筑密度或立体地形。岛屿外轮廓仍是矩形；中央装饰高楼、低面数旧树/山体与新原创建筑的风格还不完全统一；标牌和HUD仍会遮挡全图边缘，窄屏远处标牌仍可能裁切。后续应继续统一大型外围地形与旧楼群体量，避免重复加零碎道具。

未验收完整自然局、全图所有功能、所有镜头、实体手机帧率/内存或主观听感。只在软件WebGL和浏览器视口下检查。120格拓扑、完整地图数据、经济及存档结构未改；未推送、发布或绕过认证，旧检查点保留。
