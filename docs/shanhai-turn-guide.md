# 短局试玩：开局、决策与同行者反馈

本轮以真实页面试玩定位并修复三组体验问题，没有增加经济规则、任务系统或存档字段。

## 试玩观察与对应修改

1. **新玩家找不到主要操作。** 修改前从新开局进入，1440×1000桌面的行动区顶部在约970px；390×844手机在约1384px。委托、故事、职业能力排在掷骰之前，而胜利条件要翻帮助才能明确。现在先显示“本季结束净值最高获胜”和“掷骰→经营/路过→结束回合”，说明支线是可选玩法；当前行动与遥控卡前置，其他内容保留在后方。手机新开局/继续旅程定位到目标和操作区，动画结束、AI交还回合及接委托后在必要时回到行动区。定位同步完成，避免按钮恢复后再被下一帧滚动移走。角色对白不再作为悬浮块遮住侧栏操作。
2. **经营选项只有基础租金表，不便权衡。** 普通地产现在直接展示实付成本、支付后现金、本站当前与操作后参考租金以及增量。复用原租金计算，包含当前新闻、物价和产权加成。同时显示前方六步中最高的一处对手参考租金，现金不足覆盖它时提示可以先路过；没有对手收租地时也说明仍可能有事件支出。预览不是落点概率或每轮收益，明确不把尚未领取的委托奖励算进余额。商业市集保留已有两种经营方案与专用账本。
3. **AI结算后难以知道发生了什么。** 原试玩中AI购地花费1200、完成委托奖励700，现金净减500，但角色气泡仍可能显示人类上次购地或AI职业对白。现在保留最近完成的AI行动回顾：落点、新增/失去产权、等级变化、现金和点券净变动、完成委托数；可展开该段原始动态。净变动已含奖励，避免重复理解。精灵也会赋予产权，因此使用“新增产权”，不误报成付费购买。状态跳过回合有对应说明；读档中途继续AI时标明续接行动。

回顾仅存在于当前页面，不新增存档字段；刷新后最近回顾清空，原日志、实际产权与资产完全保留。所有数值来自公开状态和现有规则，不提前抽随机数、不改变AI策略或费用。
