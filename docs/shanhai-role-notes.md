# 角色选择与山路便笺

本轮完善三位角色的选择说明，并加入山城专属短互动「雨痕里的小箭头」。沿用已有规则、地图和原创素材，没有新增任务系统或存档字段。

## 可玩的变化

选择角色后显示适合的玩法、委托加成、主动能力费用与条件、限制及开局建议。对比弹窗按相同字段展示三人，可直接选择角色，AI同行者旁同步说明其能力与同规则限制。推荐依据是玩法偏好，不是未经验证的强弱排名。

- 阿屿：速递委托额外¥300，20点券接力完成近处已有速递；需要目的地在当前位置或前方两步内，不额外发第二份奖励。
- 青禾：焕新委托额外¥300，30点券在拥有未抵押地产的当前街区办花市，收入¥300–600；开局无地不可用，异地施工不算焕新。
- 星罗：无委托额外加成，花¥500制作真实遥控骰子；已有遥控或卡栏满不可用。明确开局已有一张，并提示现金制图与45点券补给的取舍。

三人初始资源与胜负目标相同；主动能力使用后第三轮恢复，实际使用卡片仍受策略机会限制。未修改AI的任何收益或规则。

山城侧栏及8、20号补给站详情可打开星罗的测绘便笺。玩家从当前位置练习读出三步停点，可按当前方向或假设反向读图。答案使用真实路线和第一处围栏；答对、答错均显示逐站路线及当前角色的原创回应。再次切换方向可重新练习，关闭后继续正常游戏。

互动免费、可重复，无奖励、无移动、不改变方向、不消耗卡片，也不消耗随机数。它只帮助理解方向与围栏，不预测状态和随机事件。AI无须参与这段无收益的教学；纯展示函数也验证了AI角色适用。蓝湾不显示此入口，旧任务与两图独立存档保留。

顺带修正地产详情的旧说明：购地需要落地，升级还可在第8轮后支付额外费用异地施工。
