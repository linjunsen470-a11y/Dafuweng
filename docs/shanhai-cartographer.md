# 第三名原创角色：星罗 · 2026-11-05

## 可玩的内容

新增地图测绘师「星罗」（xingluo），两张地图均可选择她作为玩家或AI同行者。开局新增AI角色下拉框，排除与玩家重复；默认仍保留旧角色的原同行组合。每局仍为两人、16轮，不扩展多人规则。

主动能力「行路制图」：自己的掷骰前，花 ¥500 制作一张真正的遥控骰子，每三轮一次。已有遥控骰子、卡栏已满、现金不足、冷却中或已用本回合策略机会时不可制作。制作不移动、不抽随机数、不扣点券、不占用策略机会；使用所制作的骰子时仍走原有选路及每回合一次策略规则。她没有速递/焕新委托额外奖励。能力面板写明成本、限制、结果和下次可用轮次。

AI使用相同能力入口、扣款、冷却及库存限制：制作后至少保留 ¥1,800，且点券不足45或现金达到 ¥6,000 时考虑制作，保留点券用于其他路线/道具选择。最初仅等待点券不足的启发式在几局小样本中很少展示能力，因此改为现金充裕时也可使用；没有改变所有角色的通用经济参数，也未声称三角色已经充分平衡。

## 原创视觉与动作

紫色旅行外套、宽檐帽、圆镜、黄色领巾、卷轴筒、笔记本和指南针构成新轮廓，沿用项目原创玩具角色的分件建模方法。走路摆幅与原两人不同，能力动作低头、抬臂；包含 idle、walk、celebrate、disappointed、ability、notice 六组基础动画。头像由同一GLB在Blender透明背景直接渲染；新增原创对话涵盖登船、到站、事件、购地、升级及能力，人物名称、头像和反馈不会退回旧角色。

全部几何、材质、配件、动作和文字来自本项目，没有下载模型、纹理或使用原版游戏素材。没有新增配音或角色专曲。

运行模型18,160三角面、6个合并网格、正常渲染通道28次绘制，GLB约679KiB；不加载新贴图。优化检查验证所有动画采样与原始导出一致，六个动作的首尾误差均低于0.001。真实移动端性能仍未测。

源文件及重建：

```sh
blender -b --python scripts/art/create_shanhai_cartographer.py
python3 scripts/art/optimize_shanhai_characters.py --cartographer-only
blender -b --python scripts/art/render_shanhai_portraits.py -- --cartographer-only
```

可编辑源：`art-source/shanhai/cartographer.blend`；未合并GLB和优化报告也一并保存。现有两名角色运行资产未重导出或替换。公共生成器改为可导入函数；默认旧生成命令继续只生成原来的两人，新角色使用上述独立入口。

## 不足与后续

角色采用同一原创基础体型，主要靠轮廓配件、材质和动作差异辨认，尚无独立面部表情系统或专属剧情。AI为简单预算启发式，¥500及三轮冷却还需真人多局比较；本轮只验证功能和基础兼容，不把短局试玩当作平衡结论。旧的主观音乐试听限制仍未解决。

下一步可用三种角色各完成少量不同路线的整局试玩，比较制图、委托和地产经营的选择是否都清楚、有用，再调整角色参数或补充人物剧情。
