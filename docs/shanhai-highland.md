# 第二张原创章节地图：枫谷山城

2026-11-05，基于 c8c8e9d2 的同一独立分支继续开发。

## 可玩内容

启程页可在「蓝湾海岸」和「枫谷山城」间选择。山城入口为 `/shanhai.html?map=highland`，仍为两名原创角色、单人对AI、16轮经营。24站采用新的山路坐标环线；枫林驿路、陶窑街市、云台茶坡有独立名称、价格、租金与建设成本。普通购地从 ¥1,000 到 ¥2,200，12号枫谷集会所可选商场或花园。

4、10、16、22号分别提供收茶、试烧、茶坡互助和护林留言。每封来信有三个明示成本与风险的选择，涉及现金、点券及已有委托期限。沿用统一支付和事件结算入口，AI按同样价格、概率和收益选择。委托、职业能力、产权升级、花园邻地视图、遥控骰子及回合回顾可以继续使用。

画面改为暖色山地阶台、远山、茶田、秋色树木与古窑会馆、谷口茶庄、歇脚凉亭。山体和地形为本轮原创程序几何；建筑、植物、角色和配乐复用已有原创资源，采用秋色材质。没有引入第三方美术或原版游戏素材。

## 最小基础与兼容

地图通过现有引擎注册，仅章节启程页提供入口，旧五图入口不变。会话、事件查找、区域显示、三维场景改为接受地图ID；切图通过页面导航重新创建会话和场景，避免增加运行时切换状态机。

蓝湾继续使用原 `shanhai-coast:save:v1`，山城使用 `shanhai-highland:save:v1`，各自自动保存与恢复；拒绝把另一张地图的快照恢复到当前场景。存档字段结构不变。山城不提供沿海渡轮、码头邻里或花灯故事，AI也不会偷偷执行这些功能；原蓝湾内容保持可用。

为了复用已稳定的经营和邻地计算，本轮保留24站的设施类型顺序与12号商业、11/13/14号花园邻地关系。山路地理布局不同，但仍是单环，没有分叉或专属交通系统。
