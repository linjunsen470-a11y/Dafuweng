# 本季结算与重玩入口

## 本轮问题

旧结算仅显示总资产、现金、委托和故事标题。排名只按净值排序，未处理引擎的现金同分规则及提前破产结束；固定“16轮经营结束”也不适合提前结束。恢复存档后直接重玩使用启程页默认角色，可能与刚结束的阵容不一致。

## 交付

新增只读结算摘要，保留引擎实际胜者。存续玩家按净值、现金、席位排序，破产者排在其后；不改胜负判定。标题使用当前地图、实际结算轮次与结束原因。

每人展示排名、你/AI、原创头像、总资产、现金、土地净值、建筑估值；存在存款、股票、企业权益时也列出。数据直接来自calculateAssetBreakdown，必要时列取整调整，确保分项合计等于引擎总资产。抵押额已扣入土地净值，卡片不计净值，建筑估值不等于出售报价。保留委托完成数与收入、对应地图故事结局或进度，注明委托收入不重复加总。

回顾从存档保留的最近50条日志提取经营、来信、角色能力、路线道具和委托各自最新的一个片段，按日志原顺序显示原文。明确不是完整对局历史；旧存档无日志时显示缺失说明，不编造事件或胜负原因。没有新增全局事件账本或永久进度系统。

结算顶部提供三个可实际操作的入口：

- 同阵容重玩本图：从结束的真实阵容同步角色和AI，重开第1轮；明确覆盖本图结算存档。
- 选择角色再开始：回到启程页并保留结算存档，可调整角色或重新查看结算。
- 去另一张地图启程页：保存当前结果后切图，保留两图各自存档；切图本身不直接开始新局。

关闭结算可查看棋盘，侧栏“查看经营结果”随时重开。金色首名卡片、原角色头像与两图原创收尾短句提供轻量表现；没有新增模型、奖励或经济规则。

## 局限与下一步

关键片段受原有50条日志限制，无法准确还原整季转折，不提供收益因果归因或完整时间线。没有永久赛季档案、额外奖励、自动导出或新配音。真实手机性能和先前音乐主观试听仍未验收。后续可以观察真人是否能从资产构成理解胜负，并据此调整结算信息密度；不宜仅为记录更多内容叠加永久系统。
