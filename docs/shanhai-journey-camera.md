# 连续回合的步行视角（2026-11-06）

## 实际复现

两图使用四人固定种子314准备存档，通过原有“同格人物 → 近看这处站位”按钮近看起点，然后玩家实际用遥控骰走6步、路过地产、交棒给三名AI，至第2轮。海岸1100px普通动画并开启AI速览；山城390px使用系统减少动画。记录每段步行起终点在画布中的投影，并截图观察玩家停靠位置。

修改前近看视角不会随着出发调整：海岸2段、山城3段移动至少一个端点在画布外。手机截图里玩家已经走到6号地，画面却仍围着起点的三名AI，难以跟随当前行动者。详见qa/journey-baseline-report.json。

## 小范围修复

掷骰展示前检查当前地点和本次步行预计路线是否能容纳角色脚下、身体与姓名区域。路线已经在视野内时完全保留镜头；出框时才拉回能够容纳棋盘的视角，预留边缘和底部操作区空间。

调整保留原观察方向与俯仰角，只移动观察中心、缩小视野倍率，没有强制旋转。每次行程开始前最多处理一次，不逐格追赶或抖动。普通模式使用220毫秒平滑过渡并跟随倍速；AI速览、系统减少动画或画布不在视口时立即调整，不增加等待。调整期间临时锁定拖动，完成后恢复原控制设置。

读取存档继续未完成移动也使用相同检查。乘船沿用既有全景处理，本轮不改航行动画。规则、行走路径、角色动作、移动时长、随机数、存档及默认玩法均不变；没有新设置、依赖或框架。

## 限制

这是画布边界的取景修复，不保证每种角度都没有建筑遮挡，也不自动滚动网页到棋盘。手机全局视角中的人物比近看时小；仍可手动近看，下一次路线出框才会再次拉回。尚未验证真实手机GPU表现、任意窗口比例或长时间连续镜头操作。没有新增永久镜头偏好，也没有逐格跟随系统。
