# 原创区域住宅与环境动态

本轮从 `f20a444` 继续，资产由 Blender 4.3.2 脚本生成，不依赖外部模型、纹理或字体。所有模型及几何动态均为本项目原创，项目所有者可使用、修改及再分发。

## 三组四级住宅

| 区域 | L1–L2 | L3–L4 | 四级三角形数量 |
| --- | --- | --- | --- |
| 港口 | 架高木廊、横向木板墙、陶瓦坡顶；二层投影阳台 | 增加瞭望阁、叠层木栏、双屋顶小阁 | 1,468 / 2,216 / 3,652 / 4,984 |
| 商街 | 骑楼店面、条纹棚、平屋顶与女儿墙 | 退台公寓、屋顶花台、角部小塔 | 1,248 / 1,856 / 2,656 / 3,352 |
| 艺坊 | 玻璃花廊、木格架、绿屋顶、种植阳台 | 屋顶温室、退台花园、叶形屋顶装饰 | 1,228 / 2,052 / 2,808 / 3,264 |

共 12 个预制体、30,784 三角形，单个模型不超过 5,000 三角形。每区高度随等级递增；所有模型宽度 2.25、深度不超过 2.13 世界单位，接入时统一缩放 0.87，不扩大原地产占地。侧面与背面也有窗户，支持旋转观察。

- 根节点名：`res_harbor_1..4`、`res_market_1..4`、`res_garden_1..4`。
- 所有预制体原点位于地面中心，保存时重叠在原点；GLB 为 Y 向上、入口朝 +Z。应按名称克隆，不直接显示整包。
- `residenceModel(tile, level)` 只将原有地点与等级映射到外观。L0 沿用原空地，商业市集沿用原市场建筑；没有新等级、存档字段或玩法条件。
- 材质复用原调色板，沿用区域配色缓存与静态合批。

## 产权与升级标记

已有的产权底座、旗帜继续使用业主颜色；地块前缘新增四个短格，以亮金色数量显示 L1–L4，L0 无亮格。已购地产另有“业主 · L等级”标牌，不依赖颜色猜测。更新外观时会移除旧标牌，易主与等级变更不会叠加标签。

桌面显示已购地产标牌；手机仅显示当前选中地块的标牌，避免 16 处地产标签覆盖棋盘。实际业主、价格与等级仍可通过原地块详情查看。商业市集虽未新增升级轮廓，也有一致的等级标记。

## 轻量环境动态

`SliceAmbience` 生成两只低多边形海鸟及两圈喷泉涟漪，共 4 个 mesh；使用独立呈现时间，不调用游戏随机数、不写入存档。无纹理、无动态投影、无额外定时器，涟漪使用单次双面绘制。离屏或标签页不可见时暂停更新时间；系统启用“减少动态效果”时隐藏海鸟和涟漪，原装饰帆船也保持静止。

## 重建与必要检查

```sh
blender -b -t 4 --python scripts/art/create_shanhai_residences.py
npx vitest run tests/shanhai-residences.test.js tests/shanhai-scenery.test.js
npm run build:shanhai
node test-shanhai-residences.js
```

保存 `public/shanhai/models/residences.glb`、manifest、`art-source/shanhai/residences.blend` 和完整生成脚本。`qa/residences-old-save.json` 来自上一提交在独立自动化浏览器中真实开局、移动和购地，不是用户的私人存档。

检查覆盖预制体、有限几何、占地和递增高度、原等级映射、标牌替换、动态暂停与减少动态设置；浏览器核对上一提交存档恢复、实际回合继续、各区各级外观、手机选中标牌与环境动态。

满建筑截图是仅用于呈现的夹具，不代表真实玩家经营进度；夹具前后对局数据与存档未改变。截图仅在云环境本地目视检查，不打包到资料库。浏览器使用软件 WebGL，绘制量对照不等于硬件帧率测试。没有运行全量玩法回归或批量模拟。
