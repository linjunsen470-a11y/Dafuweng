# 借道通行旗（2026-11-06）

## 检查与决策缺口

章节原有施工围栏、清路工具包、回程路签和换站风筝，已经覆盖截停、移除路障、转向和换站。缺少的是保留当前路线、牺牲本回合其他策略机会来应对对手收租的选择。核心另有未在章节背包开放的RENT_SHIELD，它从后续回合开始生效；本轮不改变该卡的旧行为或持续时间。

新增原创章节道具BORROW_PASS「借道通行旗」，定位为对地产围栏陷阱的短时反制，而非新的攻击或永久保护系统。

## 可玩规则

- 掷骰前花50点券兑换，背包容量限制照旧；使用消耗一张，只有自己是合法目标。
- 仅当前自己的行动免付对手地产租金，仍须普通掷骰；未落到收费地也消耗。使用后不能再遥控、换站、清路、异地施工或乘船，共用原每回合一次策略机会。
- 围栏仍会截停，抵达后照常消耗围栏；其他事件费用、产权、建筑、奖励和委托规则不变。对手只失去本次租金，不损失产权；下一次自己的行动重新按原状态规则处理租金。
- 已处于免租状态或无法自由行动时没有合法目标，错误目标不消耗卡片。原未来回合免租计数独立保留。

策略背包显示兑换成本和库存；目标页展示当前方向1–6步中收费落点数量、最高参考租金及本回合归零结果。预览只读取公开地块与围栏，不抽取骰子、不改状态，个人状态与后续事件不作为收益承诺。支持列表、键盘确认及棋盘自选标记；取消不消耗。使用结果和当前行动者资产栏标明本回合免租，落地明示免租结果。

AI仍优先沿用清围栏、明显有利的转向和换站选择；这些未满足时，若当前公开路线平均参考租金≥400且最高≥700，才考虑举旗。没有预知骰子。未持有时支付同样50点券，并沿用AI至少保留45点券的购买预算；当前回合不可再用其他策略，已有保护时不会重复消耗。此阈值是保守实现，不声称已经达到最优平衡。
