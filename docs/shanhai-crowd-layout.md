# 四人同格的站位、产权与交互（2026-11-06）

基于 `895b167` 的独立分支继续开发。实际页面用两图的准备存档复现：四位角色停在9号地产，星罗持有L2住宅。原手机画面将四个姓名牌纵向堆叠，业主牌与人物身体重叠；船只到站使用地块中心，而普通移动和刷新使用座位偏移，站位也不统一。

## 改动

- 同格人物沿当前镜头的水平轴排列，按2–4人适当缩小模型与脚下圆环；转镜头或人数变化时平滑调整显示站位。独处回到地块中心与原始尺寸。没有改动游戏逻辑位置、地图连接、模型资源或存档字段。
- 同格姓名牌合并为一个「9号 · 4人」入口，最小触摸高度44px，可点击或键盘打开。详情分别列出头像、姓名、当前行动者、人机身份、现金和破产标记；明确说明停留不代表产权。普通地产、商业地块都能显示该列表。
- 产权牌增加「业主」字样；挡住同格人物时移到人物下方；人数入口避让产权牌；与人物身体重叠的码头/区域装饰文字暂时隐藏，位置不再冲突时恢复。详情提供「近看这处站位」，从街区内侧看向地产，减少外侧房屋遮挡；可用原有全景按钮返回。策略目标选择期间隐藏同格入口，移动期间禁用，避免截获原有操作。
- 普通走格、换位同步、乘船下船与存档恢复共用显示落点。移动中的人物不被站位排版拉走；等候人物提前为即将抵达者让出位置，靠岸后恢复完整人数。船只临时网格清理沿用原实现。

所有计算只在显示层进行；AI仍按原规则行动。不新增渲染器、几何体、依赖或持久化系统。

## 仍有限制

远景中的模型仍小，个别角度的建筑或植物会遮住部分身体；近看视角与人物详情提供更清楚的辨认方式，未引入透视显示或遮挡建筑淡出系统。附近不同地块的其他装饰标签没有进行全局避让；极端缩放和复杂街区仍可能拥挤。镜头转动时同格棋子会平滑重新排列，是显示辅助而非道路移动。移动端只验证浏览器尺寸，未在实体低端设备测帧率，也未覆盖全部历史存档组合。
