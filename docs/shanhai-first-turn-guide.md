# 首次回合指引（2026-11-06）

## 从零试玩观察

本轮在空浏览器存储中分别开启蓝湾海岸与枫谷山城四人局，没有注入准备存档。先用棋盘实际点击13号地查看资料，再普通掷骰；固定种子314在两图均落到2号地，分别花 ¥1,200 / ¥1,000 买地，然后手动结束回合，由三名AI行动后回到第2轮。

观察到最容易产生误解的是“在地图上看地”和“实际落地经营”的区别，以及购买后仍须结束回合：棋盘查看窗口没有直接购买入口，原目标说明在买地前后保持同一段文字。已有操作按钮正确，但说明没有指出当前处在回合哪一步。这是基于实际页面流程的判断，并非新手真人测试结论。

## 改动

把原目标区中的静态回合说明替换为简短内嵌指引，仍保留净值目标，不增加弹窗、遮罩或强制教学关。

- 出发：点地图只看资料，按下方普通掷骰免费出发；委托与道具暂时都可跳过。
- 决定：实际停靠后才在下方买地、升级或路过；来信站提示先读成本风险、可选免费帮工。
- 交棒：本站处理完后按结束回合；AI行动时改为等待说明，下一回合回到出发提示。

三个步骤用文字、序号和当前步骤标记区分，不依赖颜色。可随时点“跳过引导”，原位置保留“重看回合指引”；按钮支持键盘，不重建焦点。重复渲染相同提示时不重复写入播报区域。

当原操作区需要滚回视口且引导展开时，滚到引导与操作区开头，确保落地后的下一步提示可见；收起后沿用原操作区滚动。手机可纵向滚动操作，没有新弹窗。

偏好保存在独立 `shanhai:turn-guide` 键，两图共用，不写入游戏存档。没有偏好时，新局默认展开、已有存档恢复默认收起。设置存储受限时仍可在本页跳过和重看。竞拍、破产旁观与结算有简短状态提示，不会要求错误地重新掷骰。
