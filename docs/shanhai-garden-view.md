# 花园邻地：地图与租金决策视图

本轮在商业经营之上补齐信息对应关系，不增加经济规则、资产或存档字段。

## 实际交互

地图左下角“花园邻地”、经营账本“在地图查看花园邻地”，以及11/13/14号地产详情，均可进入同一视图。镜头靠近市集，四个数字对应12号市集与11、13、14号邻地；市集金框、可增租地绿框、其他灰框。点击道路地块或下方明细可选中相同编号。颜色之外有完整文字说明，不要求玩家只靠辨色判断。

查看期间收起普通产权、角色、区域、交通和委托文字标牌，以及装饰标题和骰子展示，避免重复叠加；实际角色、建筑和产权底色保留。租金明细放在棋盘下方，桌面三列、手机纵向排列，不覆盖地图。手机编号进行轻量避让。关闭视图时移除临时标记并恢复原镜头；开始移动或AI行动时自动退出，以免看错行动目标。此视图不暂停、修改或代替规则结算。

明细按真实产权区分：

- 已拥有且未抵押的花园：显示“当前生效”，逐块列出无此花园租金、当前租金、差额、业主及等级。
- 商场：显示“改建预览，尚未生效”，按当前市集业主假设改建，显示当前与花园后参考租金；提示需要改建费并放弃本站商场租金，具体等级损失仍可在原经营账本查看。
- 无主市集：按人类玩家购入花园预览，不把其他邻地自动算作已购。
- 对手产权、无主地、抵押邻地和抵押市集：明确说明不受益或加成暂停。对手产权同时提示停靠可能付租；自家地产提示本人不付租。

所有数字复用 PropertyManager 的租金计算，包含当前物价、新闻及原有产权影响。预览使用隔离副本，不修改现金、产权、随机数、AI或任务。多座花园不重复叠加；金额只代表一次实际落地，不是每轮自动收益，个人免租等状态仍以结算为准。

## 本轮修复

普通地产详情此前只有基础租金表，现在补上当前参考租金和已生效的12号花园贡献，入口可直接查看地图。长账本关闭按钮保持在滚动区域顶部，解决手机滑到底部后需翻回顶部才能关闭的问题。查看花园时旋转镜头改为围绕当前目标，避免绕世界原点转离街区。地图点选在行动动画忙碌期间不再打开无关弹窗。

仅新增四个低面数地面边框和四个编号；刷新或关闭会释放旧几何及材质，不积累标签。视图开关不保存，刷新后默认关闭，打开时从现有存档重新计算。未引入第三方素材或依赖。

## 验证与限制

仅执行花园视图与既有商业两个测试文件，共13项检查，覆盖真实租金贡献、预览与产权风险、抵押、改建及存档恢复、重复开启清理和紧凑屏幕编号避让。独立章节构建见 qa/garden-view-build.log；页面结果见 qa/garden-view-browser-report.json。

7项真实页面场景通过，页面、控制台与资源错误均为0。页面使用明确标注的混合产权存档场景，测试真实改建按钮、棋盘点选与明细选择、旋转、普通地产参考租金、掷骰退出视图、桌面和390px手机宽度、长账本关闭、刷新恢复。截图仅在云环境目视检查，不随检查点上传。不跑全量测试或批量规则模拟。

当前仅解释海湾唯一商业地12号的影响，尚未提供全岛收益热图或概率收益预测。数字避让与视角验证覆盖默认近景及390px宽度，极端拖动/缩放仍可用“俯瞰”按钮重新对准街区；未验证实体手机帧率。仍有既有主包大小提示，游戏仍为开发版。下一步适合围绕实际短局反馈改善经营选择，而非新增平行经济系统。
