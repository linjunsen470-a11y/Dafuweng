# 两图轻量环境动态与日照（2026-11-06）

## 实际视觉变化

海岸原来已有两只海鸟和两道喷泉涟漪，本轮在近岸海面加入两道缓慢伸缩的浅色水纹。山城新增柴窑烟囱上方三缕淡烟，以及茶棚旁六片随风落下的橙色叶片；范围集中在已有场景附近，不添加盖住棋盘的雨幕、雾层或屏幕特效。

两图桌面日照强度用60秒平滑周期在原值的94%–100%之间变化。保持原光源方向、底光、产权颜色和标签；不增加移动阴影重绘。变化刻意轻微，不改变游戏天气、事件、骰子、租金或任何规则。

所有新增形状均以项目代码原创生成，使用既有Three.js基本几何和实例化绘制，没有外部素材、贴图、下载或新依赖。沿用现有海鸟、喷泉、停泊船和码头动态流程。

## 降级与控制

- 宽度不超过680px或粗指针设备：山城只保留两缕烟，隐藏风叶；海岸只显示一只鸟、一道喷泉涟漪，隐藏新增海面水纹。固定日照强度。
- 系统要求减少动画：隐藏环境动态，恢复固定日照，控制按钮说明原因；系统偏好实时变化可生效。
- 地图右侧新增「≈」环境动态按钮，支持触屏、鼠标与键盘，手动关闭也会停止停泊船摇摆和码头待机动作。角色行动和必要的游戏反馈仍保留。
- 偏好保存到独立的`shanhai:ambient-motion`键，写入失败可降级；不改变两图存档字段。隐藏页面或地图离屏时，不推进环境时间。

环境组本身桌面海岸5次绘制（旧为4次）、山城2次；手机分别只需2次和1次。新增物体不投影、不参与地块拾取，复用矩阵对象，销毁场景时释放几何、材质和实例缓冲。这里是环境组结构预算，不是整场景帧率承诺。
