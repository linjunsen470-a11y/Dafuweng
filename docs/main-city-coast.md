# 主游戏原创海岸与岛屿边界

2026-11-06，基于 `71d97ed2dd1359c73bba034515fc856aaba5b62e`，分支 `cloud/dafuweng-playability`。仅主游戏 `/` 山海都市岛。

## 改前与改后

沿用前期[原作研究与主游戏对照](richman4-map-integration.md)，本轮选择全图中最明显的矩形底座：原142×92矩形陆地、直条沙滩和仅南侧海面，使外围街道像放在切齐的桌板上；北侧直接接蓝色背景。以本轮改前实际截图为基准，没有新增平行地图。

新增原创33节点轮廓，与原城市地面纹理共用边界；削去四角并形成宽缓凹凸，保持所有地块、公共设施和道路余量。南侧浅沙色岸坡连接原港口步道，向北逐渐过渡为灰绿岩岸；海面降低到Y=-0.58并环绕岛屿。地面纹理的世界坐标保持原样，街道、广场、山地绿带不随轮廓缩放。

保留四座原栈桥，岸端延长、各补两根简单支柱；原船只和波纹高度随海面调整。没有增加可走水路或交通规则。岛身和岸坡合计194三角形，地面31三角形；没有新纹理、依赖或逐帧地形计算。新增支柱共8网格，仍须以真机衡量最终运行负担，未据此宣称性能提升。

## 尚未覆盖

本轮是一次开局存档的局部真实交互，不是完整自然对局。手机仅浏览器360px视口、软件WebGL，未做实体设备帧率/内存测试或手机全流程。未逐一近景验收四座栈桥和两艘船的全部动画周期，未覆盖全部旋转角度、夜景与其他地图流程。

海岸仍为简洁低多边形折线，局部尖角、较均匀的岸带及旧紫色设施等仍有风格差距；为保留原路网外围街道，岛屿总体比例仍受现有长方形路网约束。没有用堆积礁石或植被掩盖问题。此轮无音频修改或听感验收，也不代表达到最终《大富翁4》体验。
