## 新闻与财报

自然续玩第35轮实测两个弹层同时存在：财报的z-index更高，新闻在其后自动计时消失，可能未读就被遮掉。规则核对：`GameState.onRoundEnd()`先结息、公司分红等并生成财报，再触发随机新闻及影响。两者都是已完成结果，不含待选择的玩家决策。

现在仅将**当前打开且轮次相同**的新闻全文和全部影响卡放入财报顶部，不再叠第二个新闻弹层；明确“结算后生效”，保留先前财报的结算时点数据。新闻不随原6.5秒计时消失，与财报一起由玩家关闭。不改结算金额、触发概率、事件顺序或AI。不同轮新闻、没有打开财报时仍保留原新闻流程。顶部财报入口读取原有新闻历史恢复同轮新闻，新闻历史入口仍在。

截图复查发现财报网格曾压缩新闻影响区，已改最小内容高度并取消影响说明的省略裁切，正文可滚动、关闭按钮固定保留。初次页面对照还把每次快照自动生成的`savedAt`时间误当玩法变化，已修正检查为只忽略该时间戳，其他全部快照字段逐项比较；保留原失败报告，不将其解释为存档变化。

## 验证与边界

14项相关检查：同轮合并的全文/全部影响、保持显示直到关闭、不同轮正常新闻、历史回看、原地块范围、道路净空、模型尺寸与拓扑不变。构建、桌面/旋转和390px截图，以及独立准备局面的新闻/支路复查见对应 `qa/return-route-*` 报告。四级住宅展示和支路出发车辆属于明确准备的检查局面，不能算作自然局获得或自然走到。

补充通行检查使用原开局快照，分别把人类放在12/36/60号既有岔路并准备汽车、3枚骰子；其后通过页面掷骰并选择支路，不指定骰点。相同开局随机状态三次均掷出16步，逐步命令确认12→84…95→24、36→96…107→48、60→108…119→72全部走通，最终到27/51/75号。第一段实际收到27号点券；其余两段停在原购地/商业类型选择界面，未替玩家提交选择。分岔选路与重新汇入主路经过验证，不能据此宣称89/99公司、109小游戏等沿途落地功能已通过。部分汇合截图被原地产弹窗遮挡，不能当作支路全景美术验收。

最终新闻布局单独用同一实际组件和样式在1440/390px浏览器复查：所有影响卡位于新闻区内，与下一块财报内容不重叠，无横向溢出，底部可关闭并重新打开。证据为`return-route-news-layout-report.json`与最终新闻截图；真实游戏页面的完整快照（仅排除自动生成的savedAt时间）保持一致，见`return-route-fixes-report.json`。

仍不足：外围地形、部分西侧旧设施及支路建筑风格尚未统一；未做主观听感、实体手机、Safari或全面帧率验收。仅局部检查，没有跑全量测试。一次续玩完成40轮结果不等于长期平衡已验证。
