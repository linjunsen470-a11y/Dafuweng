# 现金浮字可见性修复

2026-11-06；主游戏山海都市岛；基线916ccd22279b67f0e7e586fc25149e67768e324a。

## 真实原因

上轮只知道现金浮字未采到，本轮直接跟踪真实RENT_PAID事件中showCash创建的两个DOM节点，从创建到移除采样样式、坐标与祖先层：

- 两个节点确实创建，文字分别为−180支付、+180收入，坐标在屏幕内，祖先层正常可见。
- CSS现金动画从opacity:0开始，在当前软件WebGL下，存活的采样帧始终opacity:0；约1.63秒后节点被原1500ms计时移除。
- 因此本环境中是真实的透明度动画未及时显示，不只是漏采或位置遮挡。不据此断言所有硬件都会出现。

## 最小修复

金额从创建起保持不透明，只动画轻微上移24px；不再依赖淡入和缩放阶段才能读取。减少动画（设置或系统偏好）时静态显示。既有1500ms移除计时、操作节奏、事件和现金计算完全不变，没有新增等待或动画框架。只有运行时CSS改动。
