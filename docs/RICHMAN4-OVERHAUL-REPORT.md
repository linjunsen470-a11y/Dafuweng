## 复现

在本工作树运行。开发时仅执行与改动相关的一条检查；浏览器脚本独立于 verify。

```sh
cd /workspace/Dafuweng-m1
npm ci
npm run dev
# 里程碑收尾
npm run verify
node scripts/qa/board-view.mjs after
# 收租或住院表现改动时
node scripts/qa/board-events.mjs
```

重建屋标使用 `blender -b -t 2 --python scripts/art/create_exchange_crown.py`。用 glTF Transform 4.2.1 的 `quantize` 将新导出的 GLB 量化至临时文件，再替换同名运行时资产。三张离线渲染在 `/tmp/dafuweng-exchange-{0,1,2}.png`。

## 第二里程碑 · 八人角色与八位巡游神明

主游戏角色 0–7 均接入独立 GLB。八份量化模型各含一个蒙皮、九个骨骼节点和全部七段标准动作。眼、眉、嘴随动作变化。持有机车或跑车的角色切换为 Ride，车轮和尘迹跟随位移。八位神明共用一份按需加载的模型包，地图巡游和肩后附身都使用对应造型。原始模型、角色姿态和神明双角度图分别见 `art-source/main/`、`qa/review/core-cast-poses.jpg` 和 `qa/review/spirits-sheet.jpg`。

两端各跑一局，共覆盖八名角色。桌面悬停查看地块，再驾驶跑车掷三骰；手机触摸查看地块，再骑机车掷两骰。两局均已观察到走格、Ride 动作、地图神明与肩后神明，并且没有页面异常。按常驻 HUD 元素可见矩形的并集直接量测，1440×900 占 **15.67%**，390×844 占 **20.91%**；中心连续净空另计为 **66.97%** 和 **75.83%**。实机图与各项读数见 `qa/review/cast-spirits-desktop.png`、`qa/review/cast-spirits-mobile.png` 和 `qa/review/cast-spirits-checks.json`。

角色可用 `blender -b --python scripts/art/create_baseball_pawn.py -- xiaoman` 重建，神明用 `blender -b --python scripts/art/create_board_spirits.py` 重建；运行时 GLB 使用 glTF Transform quantize。运行 `node scripts/qa/board-ride.mjs` 可复查实机操作。俯视镜头中角色主要靠帽形、配色和载具辨认，脸部细节在手机默认缩放下较小。后八名可选角色仍使用原模型，五级住宅与后续城市美术尚待实现。

本轮收尾运行一次 `npm run verify`，类型检查通过，127 个测试文件的 663 项全部通过，生产构建成功。

## 第五里程碑首批 · 三骰、连片租金与 AI 极速回合

主游戏按实际骰数显示一至三枚 3D 骰子，每枚独立翻滚并按规则点数定格。点数来自规则引擎，弹跳为程序动画。暂停菜单新增独立 AI 速度，提供 1×、2×、极速；极速跳过掷骰、逐格跳跃与到达演出，仍逐步结算经过地块、选路、资产与回合事件。

主地图按现有前进路线识别同街相邻地产，同一业主的连续未抵押地产按块数乘租金；遇到异主、抵押或其他地段即中断。整组垄断既有倍数与连片倍数取较大值。地块查价、购地报价与实收使用同一连片计算，地面业主色带连接相邻地块。支付连片租金时播放金币落下与金额反馈。

**实测**：桌面与手机都从正常暂停菜单切换 AI 极速，再由真人驾驶跑车掷三骰。固定局面合计八步，抵达 8 号地，向三块相连地产的业主支付 21,300；随后 AI 完成自己的回合，第 2 轮交还真人并恢复真人 1×。两端页面异常为零。抵押中间地块中断连片另有规则回归。复现运行 `node scripts/qa/board-rent-turn.mjs`，结果在 `qa/review/m5-rent-turn-checks.json`。

**视觉查看**：`qa/review/m5-three-dice.png` 是桌面真实 WebGL 画布帧，`qa/review/m5-chain-rent.jpg` 为首次手机实机收租提示的缩小图，`qa/review/m5-rent-turn-mobile.png` 保留完整视口的后续交棒画面。**剩余**：此次覆盖极速交棒，未单独计时比较三档 AI 速度。M5 的 3D 路口直选、股市红黑卡表现、卡片组合、小游戏、住院接送与配乐仍待后续打磨。

## 追加角色与街机验收

后八名角色现已使用原创 Blender 蒙皮模型。奥黛拉戴七尖冠，棠果带双辫与糖杖，黑泽隼用发髻与叠甲，米洛戴报童帽；丹尼佩戴监听耳机，莎拉配实验护目镜，宫本凌有梅花发饰与飘带，金宝宝戴虎耳帽与钱币挂饰。沿用原角色编号、能力与存档字段。

每个模型有 9 个骨骼关节、蒙皮权重与七个具名动作。离线拼图按上述角色顺序从上到下排列，每行依次为待机、行走、骑乘和欢呼。查看了四个姿态，腰带、发饰、护肩与手持物随角色保持连接。重复生成单个角色可运行 `blender -b -t 3 --python scripts/art/create_baseball_pawn.py -- danny`。完整源文件在 `art-source/main/`，游戏模型在 `public/assets/models/`，拼图在 `qa/review/cast-second-eight.jpg`。

### 公共设施入口与购地反馈（从 b53ae2c 续作）

在台湾环线，第 2 格卡片屋采用砖造印坊的阶梯山墙、深檐、双柱门廊和三张牌的立体标识。潮汐岛同一功能采用木码头摊厅、高桅双帆与背街牌架。第一次手机截图里，厚帆从背面看像实心屋顶；第二次把帆改成折面薄布，露出柱架，并补上背街标识。四张经典地图的设施用门前平台和低台阶接到街沿，带分支的设施优先展示自身建筑。山海都市岛沿用既有专属公共建筑。购地成功才会从玩家所在格飞出业主色印章，落向实际取得的地产；减少动态效果模式跳过这段表现。

**对照与复现**　运行 `node scripts/qa/board-shop-review.mjs after`。用固定随机种子从主游戏新局入场，潮汐岛 390×844 触屏、台湾环线 1440×900 鼠标。对照图左旧右新，均将正常街景相机对准第 2 格；之后恢复开局视角，点击掷骰、移动至第 3 格、确认购地。观察到两局现金均从 20,000 到 18,980，产权由空置变为玩家 0。录像来自手机浏览器，使用软件 WebGL，帧率不代表手机硬件表现。证据在 `qa/review/cardhouse-island.jpg`、`qa/review/cardhouse-taiwan.jpg`、`qa/review/cardhouse-purchase.webm`。

**判断**　原版台湾广场近景里，喷泉、围合建筑和地图边栏同时可读。两座新卡片屋已能从正常镜头按外轮廓分辨地点，台阶能把设施与对应格联系起来。但缩到手机宽度，扑克牌点数仍小；台湾街景前景屋顶、道路边缘和远处空地也缺少原版的细节层次。局部辨识取得改善，尚无充分依据认定整张地图或整体游戏达到原版。其余地图本轮没有逐一实机复验。下一刀应沿一条实际走格路线，把前景住宅屋顶、街边设施和后排建筑组织成连续的街廓，再按手机镜头审视。
