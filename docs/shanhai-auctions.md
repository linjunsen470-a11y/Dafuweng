# 破产地产竞拍：报价、AI跟价与续拍

本轮基于 `d6466143f8eadc7bf0753666997313079f3afdc6`，继续 `cloud/dafuweng-playability`。复用现有 `AuctionRules` 和 `GameEngine`，没有引入框架或修改底层经济。

## 玩法与界面

三人局中一人破产、仍有两名存续玩家时，破产名下的地产逐块进入公开竞拍。替换上一阶段统一放弃所有地块的临时处理。玩家可以输入整百报价，也可以放弃当前地块；AI根据原有估值、现金和储备判断跟价或放弃。

界面显示地块编号、名称、等级、原地价、起拍价、当前最高价/报价者、下一口最低价、报价人现金、后续地块数量，以及最近八次竞价记录。输入报价后预览成交时的现金余额；不足最低价、非整百或超出现有现金时不允许提交。可用回车确认。放弃当前地块后不能重新加入，但下一块可以参与。

起拍价、至少加¥100的规则和成交条件沿用底层引擎：所有其他竞拍者放弃或无力跟价时成交，报价阶段不扣现金。无人出价则流拍，按原规则恢复无主空地，后续可以正常购买。成交后显示产权和款项结果，用户确认后才继续普通回合。玩家自己破产时，两名AI会真正参与竞价，结束后也会先展示结果。

成交款沿用引擎规则交给债权人，无玩家债权人时交给银行。**债权人自己竞得时，先扣成交款再收到相同款项，净支出为零，但出价仍必须有足额现金。** 界面明确说明这一情况；未另加偿债上限或改动分配规则。原地价仅供对照，不承诺成交后收益。

## 双人与结束边界

**双人局一人破产后只剩唯一存续者，保留立即胜出的原规则，不进行没有竞争者的赛后拍卖。** 三人局若只剩一名存续者或已经触发比赛结束，也优先原胜负流程。本轮没有扩展主动出售地产、联机竞拍或赛后资产竞拍。

## AI暂停与存档

AI落地导致破产后，其普通回合会停在拍卖阶段，不再错误结束回合。拍卖依次处理AI报价，轮到玩家便等待输入；AI速览也适用于报价停顿。全部地块处理完毕后显示结果，再跳过已破产角色，回到正常轮转。

拍卖阶段、报价顺序、已放弃名单、最高报价、报价历史、待拍队列和随机数状态原本已存在于存档。本轮只在可选的章节账本中增加 `auctionResults`，保存本次清算的成交/流拍回执；普通回合结束后清空。旧存档没有该字段时默认空数组，不改存档版本、地图键或默认人数。

每次报价完成后保存；恢复报价阶段不重复落地或偿债，恢复成交结果不重复扣款。提交时携带当前拍卖ID，过期按钮不能把上一块地的报价施加到下一块。轮到谁、金额合法性、现金和成交转移由原引擎检查。每次AI实际报价才使用随机数，展示报价不会消耗随机数。

未跑全量测试、长期经济平衡或真实手机性能测试。AI沿用原有估值和储备启发式；债权人自购净支出为零是否带来长期失衡仍待观察。报价历史在界面只展示最近八条，完整当前拍卖历史仍随存档保存。此前主观音乐试听缺口仍在。
