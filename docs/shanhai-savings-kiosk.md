# 林场储蓄亭（2026-11-06）

## 选择依据与实际内容

山城已有茶棚、柴窑、集会所、山路交通和人物任务，但8号与20号都是相同的30点券补给，20号缺少独立的公共设施互动。本轮把20号命名为林场储蓄亭，保留原地块编号、类型、路线和30点券奖励。海岸不变。

新增原创石木柜亭：石台、灰瓦顶、木柱、柜台、存款箱、钱币徽记、长凳与通向路边的踏石。使用项目现有几何建模流程及共享材质，没有外部素材、纹理或新依赖；少于30个网格、500个三角形、7种材质，接入原静态合批。建筑位于道路内侧，模型和20号地块均可点选，有名称标示和近看入口。采用原有角色提示动作与高亮反馈，没有额外持续动画。

## 存款与现金的取舍

实际停靠、领取补给后，可选择存入¥1,000、取出全部存款，或直接结束回合。同次停靠可分次存入；操作后先展示回执，防止连续点击直接重复提交。远处点选只看预览，不能办理。原测绘便笺入口保留。

复用既有BANK_TRANSFER命令、deposit余额、净值及五轮5%利息规则，没有新建经济系统。现金用于买地与竞拍；存款也计入净值，但主动取款需再次实际停靠。欠租时原自动偿债先动用存款，因此不是免租或资产保护。界面列出操作后现金、存款及预计利息，说明余额变化会改变结果，资产栏也显示存款。

真实四人页面复查发现：原引擎是在进入第5、10、15轮时结息，而非轮末。因此本设施提示使用进入轮数；已经处于结息轮时预览下一周期，季末前没有下一周期则明确提示。本轮不改变核心经济周期。

AI使用相同的资格、按钮额度和命令，复用原现金储备判断决定存入或取出，每次停靠最多办理一次。原focus结果记录本次已办理，恢复AI已存取存档不会再次扣款。无新存档字段；旧20号补给存档可继续办理，已领点券不重复领取。
