## 实际基线

准备四人局：1号地为顾田野LV2地产，3号为洛晶晶抵押地产，6号无主。常用视角能看到不同颜色和建筑，却无法直接查看地主名字、等级、抵押或租金；实际点击1号格没有详情入口。遥控骰1点落地实际收租1200，现金20000→18800。不是自然整局。

## 实现

工具栏“🔎查地”（手机在“地图/菜单”内）打开只读面板，仅在人类掷骰前可用。可直接点选棋盘道路格，或使用原生地块列表；所选格由轻量原创圆环标记。面板显示地主、等级、抵押、当前租金牌价或默认购价、特殊格说明及道路风险；使用真实路网按当前行走方向显示下一格/分叉，按钮只查看并定位，不移动棋子。关闭或Escape返回操作；开始行动后自动关闭。

租金牌价复用PropertyManager当前计费与地主能力加成，包括地产、新闻/物价等因素；明确标注访客免租、神明与保险另计，不宣称是所有情况下的最终扣款。默认购价使用引擎报价；商业建筑具体选择可能改变报价。自身地产明确不向自己收费；队友地产注明免租，热斗模式不提供标准购租报价。没有复制原作素材、修改120格路网、经济、AI或存档。

追加点选检查时，验证脚本等待镜头目标未处理动画完成后的null，导致中断；保留camera-wait-failure记录，修正脚本而非游戏镜头。

最初中央面板遮挡所选地块，保留central-panel截图/报告；改为桌面侧边、手机更小的可滚动面板，保持底部操作区可见。手机又发现重复标题挤压租金、面板误用其他容器的CSS变量而离操作栏过远，现压缩重复文字并按真实操作栏边界定位；保留mobile-before-dock-alignment证据。

## 用户核验入口

恢复包在新目录展开后按 CONTINUE.md 恢复；本工作区运行 `npm run dev -- --host 127.0.0.1`，打开该服务提供的主游戏 `/`，不是 `/shanhai.html`。这些是云环境本地访问步骤，不是已发布的公网链接。

1. 选择山海都市岛，开局或继续存档，在人类掷骰前点击工具栏🔎；手机先打开“地图/菜单”。
2. 点道路格或用地块列表检查产权和报价；12号银行可查看13/84两个实际连接，点击只查阅不移动。
3. 对手地产租金是牌价；神明、免租与保险等最终修正另计。手机较长说明可滚动查看。
4. 关闭或Escape返回掷骰。检查过程中玩家现金、位置与卡片不应变化。

证据：`qa/map-inspection-final*-report.json` 与同名前缀截图。历史手机报告的 `bank` 字段实际采集的是4号道路（“继续前进”），12号银行和分叉在 `branch` 字段；后续脚本已将该字段改名为 `road`，没有把4号道路当银行实测。
