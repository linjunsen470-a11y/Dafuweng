# 一名玩家与两名 AI：三人对局最小完整版本

本轮沿用 `cloud/dafuweng-playability`，基于 `ecbe7cd8f6a9808dfef7d02a12fdfe2ea18684fa`。仅修改原创章节；未推送或发布。

## 实际可玩的内容

启程页默认仍是双人，可改为「三人 · 你与两名AI」。玩家选择自己的角色及第一位AI；第二位AI使用余下的原创角色，因此三人各不相同。界面列明角色能力、行动顺序与各自竞争关系。两张地图都可使用。

沿用底层多席位规则，玩家→AI1→AI2全部结束后才进入下一轮。两名AI均执行相同费用、策略机会、冷却与地产规则，围栏选址会考虑两个对手。轮转自动跳过破产或受状态限制的席位；从第二名AI的回合续存档时，不重放第一名AI。

第三席可正常买地、升级、收租、使用道具并参与原有委托和故事。三人棋子错位站立，邻近姓名错位，棋盘道具标记不再重叠。资产卡在三人模式下逐行显示，手机截图检查发现的姓名/现金挤压已修正。两个AI的回合分别回顾；破产卡片标明退出状态。

结算使用原引擎胜者与净值规则，列出三人资产、委托、故事与名次，破产者排在存续者之后。支持刷新恢复结算、同阵容重玩、返回启程页更改人数。

## 破产边界与本轮范围

检查发现底层在三人局出现首位破产者时会启动地产拍卖，但原创章节没有竞拍界面，直接接入会卡住对局。本轮采用明确展示的最小规则：所有存续玩家统一放弃破产拍卖，逐次执行底层合法的零报价放弃命令；流拍地产按原引擎恢复为无主、零级且解除抵押，可在后续落地购买。没有暗中竞价或从存续玩家扣购买款。界面开局说明、破产提示与日志均说明这一规则。

玩家先破产后可点「继续剩余对局」，两名AI继续至获胜或轮数上限，再展示三人排名。AI破产使用同一流程。双人局只剩一名存续玩家时仍按原引擎直接结束。

这是三人玩法切片，并非完整竞拍系统；无联机、队伍、第四席或额外角色。没有对三人经济重新调价。玩家提前破产后，剩余AI自动演算仍包含正常动作，长局的旁观/快进体验待改进。

## 存档

不增加存档版本、地图键或迁移层。实际人数由已有 `players` 数组保存；旧两人存档仍恢复成两人。产权、胜者、任务与能力继续按席位ID保存。

蓝湾与枫谷仍各有一个独立存档槽；双人/三人共用本地图存档槽，开始新局会覆盖本图旧局，另一张图不受影响。此轮没有新增多存档管理。
