# 主游戏东北警署地标与停留反馈（2026-11-06）

基于 17fd434，在独立分支 cloud/dafuweng-playability 工作；开始时工作区干净。沿用本地官方说明书参照 full-09.jpg 及 docs/richman4-map-integration.md：街道、地皮与公共设施要形成可理解的城市空间。本轮只借鉴这种关系，不复制原作资产。

## 观察和范围

查看全图与 42 号正常街景后，东北转角警署仍是通用发光圆底、锥顶及大图标，入口和用途不清，与已经改造的公共服务建筑脱节。选定这一现有功能地标，完成进入、停留、恢复和离开的完整局部体验，没有新增另一套事件或地图。

42 号现在是原创暖石墙、蓝灰压檐、门廊、低层值勤翼楼和侧窗格栅，配原创盾形徽记；门廊旋转朝向原道路。22 个网格、255 三角面，高约 2.57，全部在原 1.93 半径内。沿用原锚点 (50,-32.3)，不占道路或邻地产；取消原悬浮底座及摆动。95 号警署暂保留原外观。

地图标牌说明“通常停2次 · 原格继续”。到达提示解释通常暂停两次行动、角色和卡片可能改变结果；实际入狱提示使用实际剩余 jailTurns，并说明从当前格继续，避免把全局回合与个人跳过的行动混淆。保留原有豁免、转移等规则，不把通常两次写成绝对结果。

## 验证

准备原四人存档，仅将玩家位置置于 41；使用存档原有遥控卡在界面走 41→42，未注入拘留状态或跳过回合。第 1 轮入狱，随后两次个人行动跳过，第 4 轮恢复到 42，再通过原遥控道具走至 43，正常出现地产选择并选择放弃。现金在入狱/恢复/离开三个采样点均为 20000。桌面操作进入，360×640 手机视口操作离开；这是准备局面的局部对局，不是自然完整局或实体手机。

局部测试 civic-station.test.js 与 tests/turn-presentation-rules.test.js 共 7 项通过，包括模型边界、道路/地块净空、人机同规则、两次跳过、提示不改变状态、实际剩余停留数。核心地图、GameEngine、GameState、PropertyManager、AIPlayer、main.js 与基线逐字节相同；120 格拓扑、经济、AI和保存结构未改。

浏览器修改前后 admit/resume/depart 三个完整状态除时间戳外一致，新提示已在真实页面捕获。最后针对常用镜头看到的空白背墙补上后窗和腰线，仅追加模型几何；重新运行 7 项局部检查，并单独复查桌面/手机画面，未重复整段对局。完整流程证据为 qa/civic-station-final-report.json，最终外观为 qa/civic-station-visual-*。最终构建通过，保留现有包体过大警告；没有跑全量测试。
