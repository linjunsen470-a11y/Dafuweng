# 主游戏星河商务街：北侧主路与游乐支路

入口为主游戏 `/` → 山海都市岛。沿用现有57号银行、CBD_1星河商务区四块住宅（61、63、66、68）、65号事件格，以及60号分岔通向的109号小游戏设施。没有新建平行地图，没有修改120格、123条连接、经济、AI或存档结构，第五级仍未开放。

## 为什么选这一段

检查全图及实际行走后，海港与榕树老街已经有原创街景，北侧主路仍是空地、通用设施标志与大块无区分地面；紧邻60号分岔的旧粉色游乐场标志尤其抢占正常街景。选择这一段可以把原有银行、购地、事件、支路小游戏放进连续可读的城市空间。

从准备好的55号四人存档开始真实UI短段，正常掷骰6、5点，经60号选择61号主路，分别购入61号与66号地产。AI购地、住院跳回合与轮次新闻照常运行。不是从标题界面开始的完整自然对局。最初截图撞上轮次新闻弹窗，因此从精确保存的最终存档重新读取，只补无遮挡的总览及街景截图，未冒充重新跑了一段自然对局。

参照已收集的原版官方说明书，重新查看游戏界面图（PDF第9页）：用道路、地产、可辨认建筑轮廓与功能地标组织画面，不拷贝原作素材，不移植原作数值。已有参考和入口区分详见 [主游戏融合记录](richman4-map-integration.md)。

## 实际接入

- 新建原创现代住宅四级轮廓：低矮门廊、庭院公寓、退台住宅、细塔冠楼。统一灰白墙、蓝绿玻璃与暖色入口，前后立面均有细节；仍由真实产权与等级驱动，只匹配CBD_1住宅，商业地产保持原样。空地不会强行生成已建住宅。
- 57号银行采用带圆形金库标志的公共大厅，明确“现金与存款·自主调配”，仍执行原存取款界面和命令。
- 65号原随机事件格改为双面城市公告亭，明确“落地抽事件·有得有失”，不新增事件或额外奖励。
- 109号原小游戏改为低矮街角游乐屋，保留原点击金币挑战、结束和兑奖流程。功能门面朝原路格，设施与产权模型不压住实际道路。
- 两侧连续低矮铺面、地产入口、三个座椅绿化点及银行到游乐屋的短步道连接街区；60号岔路口保留空隙，不把景观铺面做成新的可走路径。住宅格加“商务”区域标识，真实分岔文字仍优先显示。
- 新模型均由 `scripts/art/create_civic_street.py` 原创程序建模，保留 `.blend`、`.glb` 和清单，无外部贴图、字体或模型。最终7个模型合计1,932三角形；不增加依赖。

## 剩余不足

这是一段完整连接到既有功能的街区，并非整座城市美术完成。其他老城和商务组、医院、魔法屋及部分夸张通用标志仍待统一；远景地面和山体过渡仍较稀疏。正常近景中无法同时容纳整条长街，需随角色移动或切换总览观察。局部遮挡处理沿用原逻辑，不能保证所有极端镜头完全无遮挡。人物依旧简化。

手机仅为Chromium视口模拟和软件WebGL，未验收实体手机、Safari、稳定帧率、完整自然对局平衡或听感。主游戏其他历史素材授权仍未全部审计，不作为可发布成品。

提交独立分支；完整Git bundle、构建与QA打包后验证CRC、逐文件SHA和旧恢复包不变。不推送、不发布、不绕过Space认证。
