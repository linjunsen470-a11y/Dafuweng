# 原版参照与主游戏地图样板（2026-11-06）

## 依据与边界

参照1998年《大富翁4》的官方说明书（Steam所附41页扫描PDF），查看了PDF第6、8–32页的规则、游戏界面、住宅图例、公司、神明及卡片道具；重点放大第9页（书页8）和第15页（书页14）。图例为五级已建住宅，不能将空地算作一级。没有把后来的资料片或手机版内容当成原版基线，也不把说明书数值直接移植成本作平衡参数。

来源：[官方说明书](https://store.steampowered.com/manual/2059810/)、[官方商店](https://store.steampowered.com/app/2059810/)、[UDN报道及大宇供图](https://game.udn.com/game/story/122089/6469219)。报道文字可读，图片下载403，未绕过；原版界面和建筑视觉核对以可读的官方PDF为准。参考文件仅置于工作区外部参考目录，不作为游戏素材提交。

主游戏数据核对：`MapData.js` 的五个可选项与 `GrandMapData.js` 的真实图连接。原创章节有独立展示及存档，不合并或改写其存档键。旧完整游戏“已有”表示代码和界面接入，不等于本轮重新验收所有经济功能。

## 融合方案与本轮范围

以主游戏的地图图结构、GameEngine和存档为准，让原创美术成为显示适配层。先做主游戏山海都市岛的海港住宅街；用真实产权等级驱动原创模型，而不是在章节再造一套股票和交通系统。后续按街区扩大覆盖，再逐项接入原创人物和设施，不一次合并两个入口。

本轮不改地块ID、分叉连接、收费、升级上限或AI规则。保留12号处分流至13/84号的实际选择。将海港BAY地组的住宅四级模型接入主游戏，门面朝道路；增加地块到道路的窄步道、院落底座与原创船屋/钟楼街景；降低岛屿地面杂讯，修正覆盖住宅地块的海面边界；开局、重开和读档直接显示当前街区，总览按钮仍可使用。连锁店、商业地产及其余区域沿用原显示，避免把不匹配的住宅套上去。

资源来自项目已有 `residences.glb`、`neighborhoods.glb`；清单注明原创建模、无外部素材/字体。加载失败保留程序建筑，恢复与换图不会依赖异步加载成功。克隆模型独立拥有几何与材质，升级拆除不会销毁其他房屋或模板。

## 实际画面发现

首次进入主游戏时，`setupLighting` 未设置 `baseAmbientIntensity`，而每帧 `updateWeather` 在用户切换天气之前就把环境光强度写成 undefined。受光道路、地产及新模型因此大片变黑。实测截图复现后初始化该基准值，增加首次天气更新的有限值回归检查。另发现海面原从z=28开始，覆盖z=32.6的住宅地块；移到沙滩外z=42起，地块现在落在陆地上。
