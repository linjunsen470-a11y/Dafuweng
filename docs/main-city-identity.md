# 主游戏人物识别与头像统一

2026-11-06；基线 c474868b8f06f4182e1b2979823c3f2bab2e5bcd；主游戏山海都市岛。

## 依据与改动

实际桌面1280×800和手机360×640开局中，棋盘人物已有发型/帽子轮廓，但玩家卡仍使用另一套全身头像，远景编号与玩家卡也没有直接对应。本轮不放大棋盘人物、不改同格间距，而是打通这两处识别信息。

- 从现有原创 CityCharacters.js 模型直接渲染四张192px透明近景头像，玩家卡、回合提示和角色反应使用同一造型。生成脚本 render-city-portraits.js 可复现；静态PNG总约100KB，不增加游戏运行时WebGL上下文或模型数量。
- 玩家卡增加与棋盘对应的1—4编号。头像按 profileId 选择，编号按玩家席位选择，兼容角色顺序调整及自定义姓名。没有改写存档中的头像、配置或技能。
- 棋盘小编号不再被建筑深度挡住，人物实体仍正常受遮挡；编号尺寸、人物尺寸及同格布局不变。不是把整个人物绘制到建筑前。

## 验证

- 改前/改后都载入既有四人开局存档，真实点击遥控骰6并完成0→6购地1122。购买事件及完整状态（时间戳除外）一致；改后记录13帧实际移动，角色保持贴地步行。
- baseline/final四人同格、手机及移动截图在qa/city-identity-*。桌面1280×800、手机360×640；两次真实右转按钮（90°）后四人同格可辨，390×844视口无横向溢出；见inspection报告。
- 旋转检查脚本首次读取已清空的镜头目标导致检查错误；修正等待条件后补查通过，保留首次失败报告。不将该脚本错误归因于游戏。
- 3项局部测试通过：UI头像和席位编号在重排角色时对应正确，存档对象不变，其他地图回退原头像；现有同格布局和遮挡恢复测试通过。
- `npm run build`通过；仍有已有的大块体积提示，未在本轮扩展处理。
- protected-report逐文件比较地图、经济、AI、游戏入口、角色资料、人物模型及同格布局，均与基线一致。120格拓扑不变。

## 限制

这是浏览器软件WebGL和手机视口检查，不是实体手机或完整对局验收。人物远景实际尺寸没有提高，极远全图中仍小；编号只是帮助定位，不能替代精细人物美术。部分选角、竞拍及特殊事件界面仍使用旧头像，本轮只统一玩家信息与回合/反应展示；其他角色和地图未替换。没有新建系统、改经济或跑全量测试；原PR的其他CI余项没有宣称修复。未推送、未部署。
