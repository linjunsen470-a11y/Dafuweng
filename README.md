# 富翁帝国 3D

基于 Three.js、Vite 和原生 JavaScript 实现的本地多人/AI 大富翁游戏。当前版本包含 5 张地图、12 个完整天赋角色、29 张卡牌、普通/大型连锁地产、现金与银行存款、股票、乐透、魔法屋、移动神明、地图机关、债务清算和版本化存档。

## 当前玩法

- 标准局、快速局、2 对 2 组队战、3 对 1 领主挑战和攻击卡决胜的热斗模式。
- 山海都市岛为 120 节点旗舰地图，含 48 块普通地产、4 块大型连锁地产、三条可切换支线和专属设施。
- 银行支持现金/存款双向调整；每 5 轮结算 5% 存款利息。
- 乐透每轮开奖并累积奖池；魔法屋提供全局财富、建筑或神明效果。
- 四位巡游神明会沿地图移动，玩家相遇后可获得对应附身效果。
- 相同随机种子可重放；AI 会评估地产回报、街区占有、股票趋势、队友地产和模式目标。

## 开发环境

- Node.js 22 或更高版本
- npm
- Chrome、Edge 或 Chromium（仅完整端到端测试需要）

```bash
npm ci
npm run dev
```

开发服务器默认运行在 `http://localhost:5173`。

## 验证命令

```bash
# 类型检查、单元测试和生产构建
npm run verify

# 在 verify 基础上运行真实浏览器流程
npm run verify:full

```

端到端测试会自行启动并关闭 Vite。无法自动找到浏览器时，可通过 `BROWSER_PATH` 指定 Chrome、Edge 或 Chromium 的可执行文件。

## 项目结构

```text
src/engine/   Three.js 场景、棋盘、棋子、骰子和音频
src/game/     游戏状态、命令、卡牌、地图和股票
src/ui/       弹窗、商店、股票、资产排行和 HUD
tests/        单元、规则契约、存档和确定性模拟测试
public/       角色、卡牌和地图素材
```

UI 和 AI 应通过 `GameEngine.execute(command)` 改变游戏状态。`CommandPolicy` 负责回合与阶段授权，`GameRules` 保存跨模块共享的规则常量。随机玩法必须使用 `GameState.rng`，保证相同种子可以重放。

## 存档兼容

当前写入 V4 存档，并保留 V1/V2/V3 恢复能力。V4 保存对局模式、存款、乐透、移动神明和地图机关状态。新增状态字段时需要：

1. 更新快照类型和 `createSnapshot`。
2. 在 `restoreSnapshot` 中为旧版本提供默认值。
3. 添加旧版本恢复和中间阶段恢复测试。

## 贡献约定

- 新卡牌必须同时提供定义、效果实现、素材和自动化测试。
- 新地图必须通过 `MapRuntime` 的正向、反向和分支路线测试。
- 修改核心规则后先运行 `npm run verify:full`。
- 不直接提交 `dist`、覆盖率文件和 E2E 截图。
