# 富翁帝国 3D

## 蓝湾海岸云端开发分支

新增原创可玩章节入口 `/shanhai.html`，原完整游戏 `/` 及五张地图保留。新章使用隔离的Three.js r187依赖、真实原规则和独立存档。

**当前为集成开发版。真实浏览器/WebGL验收受到云端执行权限限制，尚未完成，不能称作成品。** 实现、证据及待验收项详见 [开发检查点](docs/SHANHAI-STATUS.md)。独立且不含旧授权不明美术的构建命令：`npm run build:shanhai`。


基于 Three.js、Vite 和原生 JavaScript/TypeScript 实现的原创本地多人/AI 财富策略游戏。当前版本包含 5 张独立拓扑地图、16 个天赋角色、30 张策略卡、13 种独立道具、五类商业建筑、六家公司、三种带街机等级结算的小游戏、24 类城市新闻、八种巡游精灵和 V11 版本化存档。

## 当前玩法

- 标准局、快速局、2 对 2 组队战、3 对 1 领主挑战和攻击卡决胜的热斗模式。
- 五种模式拥有独立目标中心与实时进度；快速局提高收入并加速经济周期，组队战共享起点分红，领主挑战按周期增援，热斗模式压低被动收入并强化攻击淘汰。
- 十六名角色拥有独立人设与事件台词；买地、升级、交租、卡片、神明、危机和破产会触发头像气泡，双边租金结算会依次呈现双方反应。
- 八种巡游精灵拥有独立名称、回合效果与地产能力；精灵会沿棋盘移动、碰撞附身、擦肩转移并在期限结束后离场，AI 会评估分岔路线上的精灵收益与风险。
- 卡片屋采用按地图、店铺与轮次刷新的限定货架；到店可领取角色天赋点券、享受专属折扣并购买限定卡片/道具，AI 会按策略与背包容量自主选购。
- 五类大型商业设施拥有独立经营效果：公园提供休憩免疫、商场返还会员点券、旅馆使用独立入住状态、能源驿站强化后续移动、研究所同时产生访客与业主技术收益。
- 山海都市岛为 120 节点旗舰地图，含 48 块普通地产、4 块大型商业地产、三条可切换支线和专属设施；其余四图也有独立路线、公司和小游戏组合。
- 潮汐交通控制塔可统一锁定三处岔路为主干道或探索支线，并预览节点、设施、玩家分布和租金风险；AI 会按路网经济价值选择方案。
- 五张地图均采用原创程序化配乐，拥有独立速度、和弦、低音与主题旋律；音乐会随雨雪、雷暴和昼夜变化动态滤波，并为回合、骰子、交易、建设、危机与胜负提供分层音效反馈。
- 掷骰后进入电影式移动镜头：棋子拥有玩家色路径光轨、逐格行进进度、途经地点提示与落地冲击；购地、升级、租金、策略卡、魔法、委托和破产均有分级事件标题，并完整适配减少动态效果设置。
- 地产投资窗口直接使用五级原创建筑图集，并提供规则引擎权威报价、街区收集与垄断预告、LV0–LV4 租金成长、单次收益率、回本次数和投资前后现金预览；桌面与小屏均无横向溢出。
- 卡片商店与背包升级为策略决策中心：30 张卡按行动、地产、干扰、防护、财富与奇策分类，提供四档稀有度、独立卡面、目标范围、使用时机、合法目标数、禁用原因和战术参谋提示；重复卡自动合并计数。
- 山海资产管理中心支持现金/存款双向精确调配、比例预设、流动性风险提示和下一期收益预测；每 5 轮结算 5% 存款利息。
- 每五轮统一结算乐透、存款利息、公司盈亏与股东分红；最大持股者自动成为董事长。
- 山海城市乐透支持单次选择至多三组号码、冷门智选、投注拥挤度与期望回报预览，并在周期财报中公布中奖者和滚存奖池。
- 每个经济周期结束会发布可回看的城市财报，汇总乐透开奖、玩家净流入排行、存款利息、公司经营损益、股东分红与六支股票走势。
- 48 张机会事件拥有财富、委托、补给、旅途、地产、市场与奇迹分类，以及标准至传奇稀有度和专属命运卡翻转演出。
- 现金不足时进入财务清算中心，可按缺口提取存款、部分卖股、出售建筑或抵押地产；资不抵债则进入破产司法拍卖。
- 魔法屋采用 10 种目标条件与 10 种结果组合；八位巡游精灵可附身、驱散和转移。
- 魔法屋使用可视化符文组合台，施法前会展示真实命中玩家、现金与地产状态、效果威力、预计影响、自伤风险和无效原因；AI 与玩家共享同一套组合合法性规则。
- 步行、机车和汽车分别支持 1、2、3 颗骰子；未来研究所拥有五级科技树、项目队列、董事长加速和按回合交付的高级道具。
- 玩家交易大厅支持地产、卡片与道具挂牌，显示参考估值、折溢价、有效期和完整交易流水，AI 也会参与买卖。
- 地产经营中心展示区域垄断进度、实时租金和地产净值，并支持连锁改建、自主拆楼、抵押与赎回，AI 会按资金和策略经营组合。
- 公司董事会允许最大股东使用公司金库制定扩张、分红、稳健或创新政策；六类董事长特权会影响购物、保险、交通、建设、研发和材料回收。
- 同屏多人带隐私交接遮罩；存档支持多槽、IndexedDB 镜像、JSON 导入导出和 V1–V7 迁移。
- 安装为 PWA 后可离线开新局；相同随机种子可完整重放。

## 开发环境

- Node.js 22 或更高版本
- npm
- Chrome、Edge 或 Chromium（仅完整端到端测试需要）

```bash
npm ci
npm run dev
```

开发服务器默认运行在 `http://localhost:5173`。

## 验证命令

```bash
# 类型检查、单元测试和生产构建
npm run verify

# 在 verify 基础上运行真实浏览器流程
npm run verify:full

```

端到端测试会自行启动并关闭 Vite。无法自动找到浏览器时，可通过 `BROWSER_PATH` 指定 Chrome、Edge 或 Chromium 的可执行文件。

## 项目结构

```text
src/engine/   Three.js 场景、棋盘、棋子、骰子和音频
src/game/     游戏状态、命令、卡牌、地图和股票
src/ui/       弹窗、商店、股票、资产排行和 HUD
tests/        单元、规则契约、存档和确定性模拟测试
public/       角色、卡牌和地图素材
```

UI 和 AI 应通过 `GameEngine.execute(command)` 改变游戏状态。`CommandPolicy` 负责回合与阶段授权，`GameRules` 保存跨模块共享的规则常量。随机玩法必须使用 `GameState.rng`，保证相同种子可以重放。

命运格会签发四类跨回合城市委托：环城、地产建设、策略卡与地标巡访。委托拥有独立期限、进度、奖励和到期代价，并随存档完整恢复；HUD 会同时展示所有玩家当前进行中的委托。

## 存档兼容

当前写入 V11 存档，并保留 V1–V10 自动迁移能力。V5 保存道路实体、独立库存、公司、拍卖、交易报价、研究队列、经济周期和小游戏状态；V6 新增城市新闻历史与影响摘要；V7 保存多轮拍卖参与者、弃权状态和竞价记录；V8 保存市场挂牌有效期、参考估值与交易流水；V9 保存公司政策、执行轮次与历史经营结果；V10 固化连续委托和完整巡游精灵状态；V11 新增可序列化比赛统计与同配置重赛信息。新增状态字段时需要：

1. 更新快照类型和 `createSnapshot`。
2. 在 `restoreSnapshot` 中为旧版本提供默认值。
3. 添加旧版本恢复和中间阶段恢复测试。

## 贡献约定

- 新卡牌必须同时提供定义、效果实现、素材和自动化测试。
- 新地图必须通过 `MapRuntime` 的正向、反向和分支路线测试。
- 修改核心规则后先运行 `npm run verify:full`。
- 不直接提交 `dist`、覆盖率文件和 E2E 截图。
