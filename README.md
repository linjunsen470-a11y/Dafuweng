# 富翁帝国 3D

基于 Three.js、Vite 和原生 JavaScript/TypeScript 实现的原创本地多人/AI 财富策略游戏。当前版本包含 5 张独立拓扑地图、12 个天赋角色、30 张策略卡、13 种独立道具、五类商业建筑、六家公司、三种小游戏、24 类城市新闻、八种巡游精灵和 V8 版本化存档。

## 当前玩法

- 标准局、快速局、2 对 2 组队战、3 对 1 领主挑战和攻击卡决胜的热斗模式。
- 山海都市岛为 120 节点旗舰地图，含 48 块普通地产、4 块大型商业地产、三条可切换支线和专属设施；其余四图也有独立路线、公司和小游戏组合。
- 银行支持现金/存款双向调整；每 5 轮结算 5% 存款利息。
- 每五轮统一结算乐透、存款利息、公司盈亏与股东分红；最大持股者自动成为董事长。
- 现金不足时进入财务清算中心，可按缺口提取存款、部分卖股、出售建筑或抵押地产；资不抵债则进入破产司法拍卖。
- 魔法屋采用 10 种目标条件与 10 种结果组合；八位巡游精灵可附身、驱散和转移。
- 步行、机车和汽车分别支持 1、2、3 颗骰子；研究所可按回合研发高级道具。
- 玩家交易大厅支持地产、卡片与道具挂牌，显示参考估值、折溢价、有效期和完整交易流水，AI 也会参与买卖。
- 同屏多人带隐私交接遮罩；存档支持多槽、IndexedDB 镜像、JSON 导入导出和 V1–V7 迁移。
- 安装为 PWA 后可离线开新局；相同随机种子可完整重放。

## 开发环境

- Node.js 22 或更高版本
- npm
- Chrome、Edge 或 Chromium（仅完整端到端测试需要）

```bash
npm ci
npm run dev
```

开发服务器默认运行在 `http://localhost:5173`。

## 验证命令

```bash
# 类型检查、单元测试和生产构建
npm run verify

# 在 verify 基础上运行真实浏览器流程
npm run verify:full

```

端到端测试会自行启动并关闭 Vite。无法自动找到浏览器时，可通过 `BROWSER_PATH` 指定 Chrome、Edge 或 Chromium 的可执行文件。

## 项目结构

```text
src/engine/   Three.js 场景、棋盘、棋子、骰子和音频
src/game/     游戏状态、命令、卡牌、地图和股票
src/ui/       弹窗、商店、股票、资产排行和 HUD
tests/        单元、规则契约、存档和确定性模拟测试
public/       角色、卡牌和地图素材
```

UI 和 AI 应通过 `GameEngine.execute(command)` 改变游戏状态。`CommandPolicy` 负责回合与阶段授权，`GameRules` 保存跨模块共享的规则常量。随机玩法必须使用 `GameState.rng`，保证相同种子可以重放。

## 存档兼容

当前写入 V8 存档，并保留 V1–V7 恢复能力。V5 保存道路实体、独立库存、公司、拍卖、交易报价、研究队列、经济周期和小游戏状态；V6 新增城市新闻历史与影响摘要；V7 保存多轮拍卖参与者、弃权状态和竞价记录；V8 保存市场挂牌有效期、参考估值与交易流水。新增状态字段时需要：

1. 更新快照类型和 `createSnapshot`。
2. 在 `restoreSnapshot` 中为旧版本提供默认值。
3. 添加旧版本恢复和中间阶段恢复测试。

## 贡献约定

- 新卡牌必须同时提供定义、效果实现、素材和自动化测试。
- 新地图必须通过 `MapRuntime` 的正向、反向和分支路线测试。
- 修改核心规则后先运行 `npm run verify:full`。
- 不直接提交 `dist`、覆盖率文件和 E2E 截图。
